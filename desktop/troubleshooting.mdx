## The app will not start

**Symptoms**: Summer Engine crashes on launch or shows an error dialog.

- Check that your computer meets the [system requirements](/essentials/installation#system-requirements). Summer runs on Windows and macOS.
- Update your graphics drivers (Windows).
- Install the latest Microsoft Visual C++ Redistributable if Windows reports a missing DLL.
- If antivirus software quarantined a file, allow Summer Engine and reinstall.
- On macOS, move Summer to the Applications folder before you open it.

Summer bundles its own .NET SDK, so you do not need to install .NET to use C#.

## AI chat issues

### The AI does not respond

**Symptoms**: The chat keeps working and never answers.

- Check your internet connection.
- Sign out and sign in again.
- Restart Summer Engine.
- Check your credits in Studio. Add credits at [summerengine.com/studio/credits](https://www.summerengine.com/studio/credits), or turn on auto top-up.

### The AI makes the wrong change

**Symptoms**: The AI misunderstands the request or edits the wrong thing.

- Be specific: "In the player script, make the jump higher."
- Split a big request into smaller steps.
- Name the scene, node or file you mean.

See [Working with context](/guides/working-with-context) for more.

## Project issues

### Changes do not apply

**Symptoms**: The AI says it made a change, but nothing happened.

- Check that the files are not read-only and that you have write permission to the project folder.
- Look for errors in the Output panel.
- If the AI wrote a new asset file, wait for the editor to import it, or focus the editor window to start a rescan.

### Lost work

**Symptoms**: Recent changes disappeared.

- Check your version control history. See [GitHub from the Changes dock](/guides/github-from-changes-dock).
- Use **Edit > Undo** in the editor for changes made in this session.

### Slow project loading

**Symptoms**: Long delays when you open a project.

- The first open of a project imports every asset. Later opens are faster.
- Keep the project on a local SSD, not a network or synced folder.
- Exclude the project folder from antivirus scanning.
- Do not delete the `.godot/` folder in your project. It holds the imported assets, and deleting it forces a full re-import.

## Sign-in problems

### You cannot sign in to the app

- Reset your password on [summerengine.com](https://www.summerengine.com).
- Check that a firewall does not block Summer Engine.
- Sign in on the website first, then try the app again.

### Your agent says you are not signed in

**Symptoms**: Your agent's Summer tools say you are not signed in.

- On your computer: run `npx -y summer-engine@latest login --force`.
- Hosted MCP: remove `https://mcp.summerengine.com/mcp` from your agent, add it again and sign in.
- Summer has no API key. Your agent signs in with your Summer account in the browser.

## Bug reports

When you report a bug, include:

- Your Summer Engine version
- Your operating system
- Steps to reproduce
- Error messages or logs
- Project details, if relevant

**Log locations**: Summer writes a `godot.log` file per project. The folder name is `Godot`, not `Summer`, and `<project>` is `config/name` from `project.godot`.

- Windows: `%APPDATA%\Godot\app_userdata\<project>\logs\`
- macOS: `~/Library/Application Support/Godot/app_userdata/<project>/logs/`

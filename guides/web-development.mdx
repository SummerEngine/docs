Summer Engine, the game engine built for AI, exports games that play in the
browser. This page covers what is different about a web build and how to ask
your agent for one. For file formats and limits, see
[Export your game](/publishing/export).

## How a web build works

A web build is a `.zip` with `index.html` at its root. The browser downloads it
and runs your game as WebAssembly.

| Your project | What to do |
|---|---|
| Forward+ or Mobile renderer | Your agent runs `summer_export_game` with `targets: ["web"]`. It uses Summer's WebGPU web template with threads off. |
| Compatibility renderer | Use a standard web export from **Project → Export** (WebGL 2). `summer_export_game` refuses Compatibility projects. |

The web template is not always installed. Your agent can check and install it
with `summer_export_templates`. See [Export templates](/publishing/export#export-templates).

**Threads.** Keep thread support off. On summer.games, a build without threads
plays in a frame on the game page. A build with threads opens in its own tab.

## Ask your agent

```
Export my game for the web and tell me the file size.
Make the controls work with touch and with a mouse.
Scale the UI so it works at 1280x720 and on a phone in portrait.
Show a loading screen until the main scene is ready.
Find the largest textures and audio files and make them smaller.
```

## Write browser code

Put code that only runs in the browser behind `OS.has_feature("web")`. Then the
same script works in the editor and on desktop.

```gdscript
extends Node

var _on_resize_ref: JavaScriptObject

func _ready() -> void:
    if not OS.has_feature("web"):
        return
    # Read a value from the page.
    var lang: String = JavaScriptBridge.eval("navigator.language", true)
    print("Browser language: ", lang)
    # Listen to a browser event. Keep a reference to the callback.
    _on_resize_ref = JavaScriptBridge.create_callback(_on_resize)
    var window := JavaScriptBridge.get_interface("window")
    window.addEventListener("resize", _on_resize_ref)

func _on_resize(_args: Array) -> void:
    print("The browser window changed size")
```

**Saves.** Files you write to `user://` in a web build live in the browser's
storage on that device. They are lost when the player clears site data. To keep
progress across devices, save it with Summer. See
[Save player progress](/build/player-progress).

**Audio.** Browsers block sound until the player clicks or presses a key. Start
music after the first input, for example on a "Click to play" screen.

## Keep it small

Players wait for the download before the game starts.

- Use textures at the size the game shows them.
- Use Ogg Vorbis for music and long sounds.
- Remove assets the game does not use.

Ask your agent: "List the 20 largest files in my export and how to make each
one smaller."

## Publish it

- **summer.games:** your agent exports, uploads and sends the build to the
  game's owner for approval. See [Create and publish your game](/publishing/summer-games).
- **itch.io or your own site:** upload the same `.zip`. See
  [Publish on itch.io](/publishing/itch-io).

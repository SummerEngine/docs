Summer Cloud was a research preview that synced a whole project folder,
assets included, between machines with the `summer cloud` commands. It was
removed in summer-engine 3.0, together with its MCP tools. Nothing in Summer
Engine, the CLI or the MCP syncs projects today.

## Move a project between machines

Keep the project in Git. Code, scenes and settings merge well there. For big
binary assets such as 3D models, textures and audio, add Git LFS to the same
repository.

## Get your game to players

To share a game, publish it. Your agent exports the game, uploads a build and
sends it to the game's owner for approval.

## If you used Summer Cloud

A project bound with summer-engine 2.x may have a `summer-cloud.json` file at
its root and a `.summer/local/cloud/` folder. Nothing reads them any more, so
you can delete both. A `~/.summer/cloud-token` file from a 2.x sign-in is never
read; `summer logout` removes it.

A card or turn-based game is a duel of decisions. Two players of similar skill
meet, take turns against a clock, keep their hands secret, and a win moves
their rating. Because the server holds the rules and the cards, nobody can
peek at the other hand or play a card they don't have. Summer gives you each
of those pieces. This page shows how they fit together.

## How it fits together

<img className="block dark:hidden" src="/images/guide-art/games-like/card-games-light.svg" alt="The card game loop: two players of similar rating are matched, take turns on a clock kept by the server, see only their own hand, and both ratings move before they play again." />
<img className="hidden dark:block" src="/images/guide-art/games-like/card-games-dark.svg" alt="The card game loop: two players of similar rating are matched, take turns on a clock kept by the server, see only their own hand, and both ratings move before they play again." />

A player presses Play, and matchmaking finds an opponent with a similar
rating. Summer starts a server for the duel, which deals the cards, runs the
turn clock and checks every move. Each player's game only ever learns its own
hand. When the game ends, the server reports the result and both ratings move.

## Build the signature features

### Hidden hands and server-checked turns

<Prompt description="**Add hidden hands and turns.** Each player sees only their own cards; the server checks every play.">
In my Summer project, make my card game fair: the server shuffles and deals,
each player's game sees only its own hand, and the server checks every play
before it happens. Use the Summer `multiplayer-state` skill; if you don't have
it installed, find it in the Summer library.

- Both players see the board, the turn and the clock the same way.
- A play out of turn, or of a card the player doesn't hold, is refused.
- If the turn clock runs out, the server ends the turn.

Read my project first and tell me what you'll change. Then test it with Local
Play and tell me what each player saw.
</Prompt>

### A rated ladder

<Prompt description="**Add a rated ladder.** An Elo rating after every game and a top 50.">

50 and the player's place. Use the Summer `summer-matchmaking`,
`summer-match-results` and `summer-leaderboards` skills; if you don't have
them installed, find them in the Summer library.

Read my project first and fit this into my existing menus. Then test the end
of a game with Local Play, and tell me what I can only check once the game is
hosted.
</Prompt>

A party game is quick to join and loud to play. Friends jump in together,
strangers fill the rest of the match, short rounds keep everyone laughing, and
a running count of wins gives players a reason to come back. Summer matches
hold up to 16 players, a good size for an Among Us crew or a round of
Fall Guys-style chaos. This page shows how the pieces fit together.

## How it fits together

<img className="block dark:hidden" src="/images/guide-art/games-like/party-games-light.svg" alt="The party game loop: a player presses quick play, up to 16 players are placed in one match, they play short rounds, and the results add wins to the board before they play again." />
<img className="hidden dark:block" src="/images/guide-art/games-like/party-games-dark.svg" alt="The party game loop: a player presses quick play, up to 16 players are placed in one match, they play short rounds, and the results add wins to the board before they play again." />

Players press Play, alone or with their party, and quick play fills a match.
Summer starts a server for it, where your rules run the rounds, hand out
secret roles and keep the score. When the match ends, the server adds each
winner's win to the board, and everyone can jump straight into the next one.

5. `summer-world-chat`: talk in the match.

## Build the signature features

### Secret roles

<Prompt description="**Add secret roles.** The server deals roles; each player sees only their own.">
In my Summer project, give every player a secret role at the start of each
round, like the impostor in Among Us. Use the Summer `multiplayer-state`
skill; if you don't have it installed, find it in the Summer library.

- The server picks the roles, and each player's game learns only its own.
- The server checks every action against the player's real role.
- When the round ends, the server reveals everyone's role.

Read my project first and tell me what you'll change. Then test it with Local
Play with [N] players and tell me what each player saw.
</Prompt>

### A board of total wins

<Prompt description="**Add a wins board.** The server counts each player's wins; everyone sees the top 50.">
In my Summer project, add a score board that counts each player's total wins.
Use the Summer `summer-leaderboards` skill; if you don't have it installed,
find it in the Summer library.

The server adds a win for each winner when a match ends. Add a screen with the
top 50 and the player's own place, and keep the game working if the board
can't be loaded. Tell me what I can only check once the game is hosted.
</Prompt>

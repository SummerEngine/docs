Install the Summer app on Windows or Mac. For a coding agent, add the `summer` command.

## Install the Summer app

Download Summer from [summerengine.com/download](https://www.summerengine.com/download).

<Tabs>
  <Tab title="Windows">
    Run `SummerEngine-<version>-Setup.exe`. Summer installs for your Windows user and opens.

    Windows SmartScreen may show a warning while Summer's new signing certificate builds its reputation. Click **More info**, then **Run anyway**.
  </Tab>
  <Tab title="macOS">
    Open `Summer.dmg` and move **Summer** into your Applications folder, then open it. macOS asks you to confirm an app downloaded from the internet: click **Open**.
  </Tab>
</Tabs>

**If everything worked, you see:** Summer's Home, with one message box. Sign in in your browser, then follow [Quickstart: Summer app](/quickstarts/fresh-project) to make your first Summer game.

## Install the summer command

For a coding agent, or for scripts. It needs [Node.js](https://nodejs.org) 22 or newer.

<CodeGroup>

```bash No install
npx -y summer-engine@latest --version
```

```bash npm
npm install -g summer-engine
```

```bash Homebrew (macOS)
brew install summerengine/tap/summer
```

</CodeGroup>

On Windows, install Node.js with `winget install -e --id OpenJS.NodeJS.LTS`, and type `npx.cmd` in PowerShell in place of `npx`.

Then let the command install Summer Engine, create a starter project and open it, all in one step:

```bash
npx -y summer-engine@latest dev
```

To connect an agent, see [Quickstart: coding agent](/quickstarts/coding-agent).

**Check that it works:** `npx -y summer-engine@latest --version` prints the version, such as `4.8.0`. `npx -y summer-engine@latest doctor` checks Node.js, Summer Engine, your sign-in and your agents in one go.

## Sign in

The Summer app signs you in the first time you open it. From a terminal, run:

```bash
summer login
```

Your browser opens the Summer sign-in page. One sign-in covers the Summer app, the `summer` command and your agents on this computer. For your own scripts, `summer token` prints an access token that lasts one hour.

Building and playing games needs no sign-in. You need it for AI assets, publishing and the [Summer API](/api/overview).

## Update

The Summer app updates itself. When a new version is ready, the top bar shows **Update ready · Restart**. You can also open **Settings > Updates & About** and click **Check for updates**.

`npx -y summer-engine@latest` always runs the newest release. For a global install, run `npm install -g summer-engine@latest` or `brew upgrade summer`.

## System requirements

| | |
|---|---|
| Windows | Windows 10 or newer, 64-bit |
| Mac | Apple silicon (2020 or newer), macOS 11 or newer |
| Memory | 8 GB recommended |
| Storage | About 2 GB for Summer, plus 3.7 GB if you start with the Sun Temple |
| Linux | No app. `npx -y summer-engine@latest install` puts the engine in `~/.summer/engine/` |

## Troubleshooting

<AccordionGroup>
  <Accordion title="PowerShell: running scripts is disabled on this system">
    Type `npx.cmd` in place of `npx`. It is the same command without the script block. Don't change the execution policy.
  </Accordion>
  <Accordion title="summer: command not found">
    Open a new terminal: terminals that were open before you installed the command don't see it yet. Or run it without installing: `npx -y summer-engine@latest`.
  </Accordion>
  <Accordion title="summer doctor says Node.js is too old">
    The `summer` command needs Node.js 22 or newer when you run it with `npx` or npm. Install the current LTS from [nodejs.org](https://nodejs.org), then open a new terminal.
  </Accordion>
  <Accordion title="My agent answers engine_not_running">
    Summer Engine is not open. Ask your agent to open your project, or run `npx -y summer-engine@latest dev` in the game's folder.
  </Accordion>
</AccordionGroup>

More fixes: [Desktop troubleshooting](/desktop/troubleshooting). Bringing a project you already have? See the [compatibility reference](/reference/compatibility).

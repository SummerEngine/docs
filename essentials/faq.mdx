## FAQ Overview

Common questions about Summer, organized by topic. Each question links to a detailed answer.

## About Summer

<CardGroup cols={1}>
  <Card title="What is Summer?" href="/knowledge-base/what-is-summer">The game engine built for AI. Any agent builds, tests and publishes a full multiplayer game.</Card>
  <Card title="What makes Summer different from ChatGPT?" href="/knowledge-base/summer-vs-chatgpt">On its own, a chat model gives you text. Connected to Summer, any agent works on your game directly.</Card>
  <Card title="Is Summer for beginners or professionals?" href="/knowledge-base/beginners-or-professionals">Both. Describe a game in plain words, or take full control of a full engine.</Card>
  <Card title="Has Summer been used for production games?" href="/knowledge-base/production-games">Yes. We built Don't Pray, a live online PvP game on Steam, in 2.5 months.</Card>
  <Card title="What's the learning curve?" href="/knowledge-base/learning-curve">Minutes to start. Go as deep as you want, with the agent explaining as it builds.</Card>
  <Card title="Can I make AAA games with Summer?" href="/knowledge-base/aaa-games">A full 2D and 3D engine. Agents do the heavy lifting; scope depends on your team and time.</Card>
  <Card title="How does Summer compare to other AI game tools?" href="/knowledge-base/summer-vs-other-tools">A full game engine built for AI, not a plugin. Any agent works inside it.</Card>
</CardGroup>

## Technical

<CardGroup cols={1}>
  <Card title="Is Summer compatible with my existing project?" href="/knowledge-base/godot-compatibility">Summer uses familiar formats, but project compatibility ranges are not fully measured. Commit first and verify imports, plugins, native extensions, and exports.</Card>
  <Card title="What if I have existing projects?" href="/knowledge-base/godot-projects">Open a committed copy in Summer Engine and review the first import. Version-sensitive plugins and native extensions need explicit testing.</Card>
  <Card title="Which AI models does Summer use?" href="/knowledge-base/ai-models">Auto picks the chat model, or choose one yourself. Asset generation uses its own backends.</Card>
  <Card title="How good are AI-generated assets?" href="/knowledge-base/ai-asset-quality">Strong for props, environments and fast iteration. Plan artist time for hero characters and key art.</Card>
  <Card title="Can I make a game with just AI, no coding?" href="/knowledge-base/ai-game-dev">Yes. Describe what you want and Summer Engine writes the code. AI game dev and vibe coding for games.</Card>
  <Card title="How do specialist agents work?" href="/knowledge-base/specialist-agents">A fixed team: researcher, builder, asset maker, verifier and advisor. The main agent hands them work.</Card>
  <Card title="How does project intelligence work?" href="/knowledge-base/project-intelligence">AI indexes and understands your entire codebase, scenes, assets, and relationships automatically.</Card>
  <Card title="What are the limitations of AI operations?" href="/knowledge-base/ai-operations-limitations">AI changes go through safe APIs. Some tasks still require manual work. Learn what works well and what doesn't.</Card>
  <Card title="Does Summer support multiplayer?" href="/knowledge-base/multiplayer">Yes. Summer runs a server for every match, plus matchmaking, parties, saves and leaderboards.</Card>
  <Card title="Can I use my own assets?" href="/knowledge-base/custom-assets">Yes. Import your own 2D art, 3D models, and audio. AI generation is optional.</Card>
  <Card title="Can I use Summer for web games?" href="/knowledge-base/web-games">Yes. Export to HTML5/WebAssembly. Deploy to itch.io, your website, or any static host.</Card>
  <Card title="How does Unity or Unreal migration work?" href="/knowledge-base/unity-unreal-migration">Use AI to research your project, create a plan, then rebuild in Summer Engine. Fresh projects: easy. Large projects: more planning.</Card>
</CardGroup>

## Account & Support

<CardGroup cols={1}>
  <Card title="Is my code safe?" href="/knowledge-base/privacy-and-code-safety">Encrypted in transit and at rest, never sold. The Privacy Policy sets how prompts and code are used.</Card>
  <Card title="Is Summer free?" href="/knowledge-base/pricing">Yes. The app and local MCP are free. Paid plans from $20/mo raise hosted AI limits.</Card>
  <Card title="How do I get support?" href="/knowledge-base/support">Ask in Discord first. Email support@summerengine.com for concrete help.</Card>
  <Card title="How do I get started with no experience?" href="/knowledge-base/no-experience">Install Summer Engine, create a project and describe the game you want. No coding needed.</Card>
  <Card title="How do I publish to Steam?" href="/knowledge-base/publish-steam">Export a build, pay the $100 Steam Direct fee, set up the store page and submit it for review.</Card>
  <Card title="How do I export to mobile?" href="/knowledge-base/export-mobile">Enable ETC2 ASTC texture format, create mobile export preset, configure signing. iOS requires Mac and Apple Developer account.</Card>
</CardGroup>

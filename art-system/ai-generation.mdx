Summer Studio generates game assets with AI models. Everything you make lands in
**My Assets**, and Summer Engine can import any of it into your game on command.

## Where to generate

- **The Create pages**: [summerengine.com/create](https://www.summerengine.com/create/image)
  has a tab for each kind: Image, Video, Audio, 3D and Effects. Pick a model, write
  a prompt, and press Generate.
- **The Studio chat**: describe what you need, for example "a low-poly wooden
  barrel" or "turn my last picture into a 3D model". The agent picks the tool.
- **The engine chat or any MCP agent**: ask for the asset while you build, and the
  agent generates and imports it in one step.

Each generation uses credits from your balance. The Generate button shows the cost
before you start.

## What each tab does

| Tab | What you can do |
| --- | --- |
| **Image** | Generate from words, guide it with reference images on models that accept them, pick an aspect ratio and a style preset |
| **Video** | Text to video, image to video, and reference to video, plus tools such as trailers and short game ads |
| **Audio** | Text to speech, sound effects, music, and speech-to-text |
| **3D** | Text to 3D, image to 3D, and several views to 3D; standard or low-poly meshes on models that support it |
| **Effects** | Game VFX the agent builds as real particle effects in your scene, and tools that turn one image into game-ready assets |

The model list on each tab is live. Models are added and retired often.

## Style presets

On the Image tab, a style preset adds a consistent look to your prompt. Examples
include Cel-shaded, Anime, Pixel Art, Retro 16-bit, Low Poly, Voxel, Claymation,
Hand-painted, Dark Fantasy, Cyberpunk and Isometric. Pick **No style preset** to
use your prompt as written.

The one-click starters (Key art, Character sheet, Item icons, Store capsule,
Environment, Pixel hero) fill in a prompt, an aspect ratio and a style for you.
They never generate on their own.

## Improve a prompt

Press **Improve** to rewrite a short prompt into a detailed one before you generate.
It works for images, 3D concepts and animation clips.

## After you generate

In Studio, or by asking the agent, you can:

- Edit an image with a plain instruction, keeping its style.
- Remove the background.
- For 3D models: auto-rig a humanoid, add animation clips, or retexture the mesh.
- Change the title, description and tags.
- Make the asset public in the Asset Store, or keep it private (paid plans).

## Writing prompts that work

Start with the subject, then add style, mood and framing:

```
[Subject] + [Style] + [Mood or lighting] + [Framing]
```

```
A brave knight in silver armor, cartoon style, bright lighting, facing forward, plain background
```

```
Seamless stone brick texture, medieval fantasy, weathered and moss-covered, tileable
```

```
Wooden game button with gold trim, fantasy RPG style, ornate carved details
```

Tips:

- **Sprites**: say the pose and direction ("facing right, idle pose") and ask for
  a plain background, then use Remove background.
- **Textures**: say "seamless" or "tileable", and name the surface.
- **UI**: name the element and its states ("normal, hover and pressed").
- **3D**: describe one object with a clear silhouette and a flat base. For best
  results, make a clean picture first, then use image to 3D.
- **Unwanted things**: say what you do not want: "no text", "no logos", "plain
  background".
- **Consistency**: reuse a prompt that worked and change one detail at a time.

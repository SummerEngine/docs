In Summer Studio, **My Assets** holds everything you generate, upload or save from
the Asset Store. Folders keep it in order. Each asset sits in one folder.

<Info>
Folders replace the older "collections" idea. Public, followable collections are
not available. The themed collections in the Asset Store, such as sword sprites or
castle assets, are curated by Summer.
</Info>

## Folders you get without asking

- **A project folder**: when you work on a project, Studio makes a folder with the
  project's name and uses it as the default folder for that project.
- **Character folders**: Studio groups a character's related assets together.

## Make and manage folders

In the **My Assets** view of Studio:

- **New folder**: name it and press **Create folder**. Open a folder and use
  **New subfolder** to nest one inside it.
- **Create folder with selected assets**: select assets first, then make a folder
  that holds them.
- **Add selected assets to folder**: move a selection into an existing folder.
- **Rename folder** and **Delete folder**: deleting a folder keeps its assets in My
  Assets.
- **Filter by folder**: show one folder's assets, or **All folders**.

You can also hide folders and see all your assets in one list.

## Ask the agent

The agent can do all of this for you. For example: "put every tree model in a
folder called Forest" or "list my folders". MCP agents use the
`assets.create_folder`, `assets.move_to_folder`, `assets.rename_folder`,
`assets.list_folders` and `assets.delete_folder` operations. See
[Assets operations](/mcp/operations/assets).

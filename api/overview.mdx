Summer is the game engine built for AI. With the **Summer API**, your agent signs in once, sends one call and gets back a file your game can load: a GLB, a PNG or an audio file, saved to your Summer library.

<Note>
**No markup on assets. Every model at the provider's list price.** Each price is on the [models page](/api/models). A failed job costs nothing.
</Note>

## Set up with your agent

Paste this into Claude Code, Codex, Cursor, Hermes or any agent that can run commands. You sign in once and choose Allow with a spend limit, and the agent makes its first asset.

```text Prompt for your agent wrap
Use the Summer API for game assets (docs: https://docs.summerengine.com/llms.txt). Run `npx -y summer-engine@latest login` so I can sign in. Then run `npx -y summer-engine@latest api run 3d/default --input '{"kind":"text-to-3d","prompt":"a stylized treasure chest, game prop"}' --download assets` and tell me where the GLB is.
```

In ChatGPT or Claude, add `https://mcp.summerengine.com/mcp` as a connector instead. See [Agents](/api/agents).

## One call

```bash
curl https://www.summerengine.com/v1/jobs \
  -H "Authorization: Bearer $SUMMER_TOKEN" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Prefer: wait=60" \
  -d '{"model": "image/default", "input": {"prompt": "a cozy pixel-art tavern at night"}}'
```

Images, voice and sound come back in the same call. A 3D model takes a few minutes: the call answers with a job id, and your agent follows it until the file is ready. With the CLI it is one command: `summer api run 3d/default --input '...' --download`. The [quickstart](/api/quickstart) makes a 3D model end to end.

## Why Summer

- **Curated and tested for games.** A short list of the best model for each job, not hundreds. Each default id, such as `3d/default`, runs the model Summer tests first and moves when a better one passes.
- **Game-ready output.** 3D models come back as GLB files with textures, and with a rig and animations when you ask. Images can come back with a transparent background. Sound effects can loop.
- **Files you keep.** Every result is saved to your Summer library, private to you, with a Summer URL and an asset id. In Summer Engine, your agent imports it by id.
- **The price before you spend.** `POST /v1/estimate` gives the exact price of a request and a quote that holds it for 15 minutes. It is free and needs no sign-in.
- **Safe for agents.** No API keys to leak. Each agent you connect has its own spend limit, and you can revoke it at any time. Retries with the same `Idempotency-Key` never charge twice.
- **One balance.** Every model draws from your paid Summer credits: your plan's credits or your top-ups. Top-ups alone are enough.

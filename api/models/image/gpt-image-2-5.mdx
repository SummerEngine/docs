## Input

Send these fields in `input`. The full JSON Schema is `inputSchema` in [`GET /v1/models/image/gpt-image-2.5`](/api/reference/get-models-model).

| Field | Type | About |
|---|---|---|
| `prompt` (required) | string | What to draw, or how to change the reference image. up to 4000 characters |
| `style` | `realistic`, `cartoon`, `anime`, `none` |  |
| `aspectRatio` | `1:1`, `16:9`, `9:16`, `4:3`, `3:4`, `3:2`, `2:3`, `5:4`, `4:5`, `21:9` | Default 1:1. |
| `width` | integer | Smallest width wanted, in pixels; give height too. Store key art: 1920 x 1080 at 16:9. 64 to 4096 |
| `height` | integer | Smallest height wanted, in pixels; give width too. 64 to 4096 |
| `numImages` | integer | 1 to 4 Default `1`. |
| `referenceImageUrl` | string | A public image URL to edit instead of drawing from nothing. up to 2048 characters |
| `removeBackground` | boolean | Also cut out the background (transparent PNG); costs a removal per image. |
| `seed` | integer | Same seed and prompt, similar image (Nano Banana models). 0 to 9007199254740991 |
| `title` | string | up to 200 characters |

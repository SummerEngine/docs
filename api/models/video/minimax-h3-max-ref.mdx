## Input

Send these fields in `input`. The full JSON Schema is `inputSchema` in [`GET /v1/models/video/minimax-h3-max-ref`](/api/reference/get-models-model).

| Field | Type | About |
|---|---|---|
| `prompt` | string | What happens in the clip. up to 4000 characters |
| `referenceImageUrls` | array of string | Reference to video: public images of the characters, props or style to keep (with a reference model, e.g. kling-4-ref). Motion transfer: the character to move. 1 to 10 items |
| `duration` | integer | Seconds; the model renders its nearest supported length. 1 to 20 Default `5`. |
| `aspectRatio` | `16:9`, `9:16`, `1:1`, `4:3`, `3:4`, `21:9`, `3:2`, `2:3`, `auto` | Default `"16:9"`. |
| `resolution` | `720p`, `1080p`, `4k`, `480p`, `768p`, `2k`, `768P`, `1080P`, `480P` | Only a quality the model offers; leave out for its default. |

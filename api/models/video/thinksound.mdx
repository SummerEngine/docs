## Example call

Sign in once with `summer login`; over HTTP, send `Authorization: Bearer $SUMMER_TOKEN` after `export SUMMER_TOKEN=$(summer token)` ([sign-in](/api/sign-in)). This job takes minutes. The CLI follows it and saves the file. Over HTTP the call answers `running` with a job id: check `GET /v1/jobs/{id}` until `state` is `done` ([jobs](/api/jobs)); the [quickstart](/api/quickstart) has the full loop.

## Input

Send these fields in `input`. The full JSON Schema is `inputSchema` in [`GET /v1/models/video/thinksound`](/api/reference/get-models-model).

| Field | Type | About |
|---|---|---|
| `prompt` | string | What happens in the clip. up to 4000 characters |
| `videoUrl` | string | An input clip (public URL, at most 20 s): restyle or reframe it, move a character with its motion, or add sound to it (e.g. kling-video-to-audio). Billed on the clip's length. up to 2048 characters |
| `aspectRatio` | `16:9`, `9:16`, `1:1`, `4:3`, `3:4`, `21:9`, `3:2`, `2:3`, `auto` | Default `"16:9"`. |
| `resolution` | `720p`, `1080p`, `4k`, `480p`, `768p`, `2k`, `768P`, `1080P`, `480P` | Only a quality the model offers; leave out for its default. |

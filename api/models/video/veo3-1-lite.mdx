## Input

Send these fields in `input`. The full JSON Schema is `inputSchema` in [`GET /v1/models/video/veo3.1-lite`](/api/reference/get-models-model).

| Field | Type | About |
|---|---|---|
| `prompt` | string | What happens in the clip. Needed without imageUrl. up to 4000 characters |
| `imageUrl` | string | A public image URL to animate (image to video). up to 2048 characters |
| `duration` | integer | Seconds; the model renders its nearest supported length. 1 to 20 Default `5`. |
| `aspectRatio` | `16:9`, `9:16`, `1:1`, `4:3`, `3:4`, `21:9`, `3:2`, `2:3`, `auto` | Default `"16:9"`. |
| `negativePrompt` | string | What the clip must not show. up to 1000 characters |
| `resolution` | `720p`, `1080p`, `4k`, `768P`, `1080P` | Only a quality the model offers; leave out for its default. |

## Example call

Sign in once with `summer login`; over HTTP, send `Authorization: Bearer $SUMMER_TOKEN` after `export SUMMER_TOKEN=$(summer token)` ([sign-in](/api/sign-in)). This job comes back done in the same call, with the file ready to download.

```bash CLI
npx -y summer-engine@latest api run sound/sfx-v2 \
  --input '{"text":"a sword hits a wooden shield","durationSeconds":2}' \
  --download .
```

```bash curl
curl https://www.summerengine.com/v1/jobs \
  -H "Authorization: Bearer $SUMMER_TOKEN" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Prefer: wait=60" \
  -d '{"model":"sound/sfx-v2","input":{"text":"a sword hits a wooden shield","durationSeconds":2}}'
```

```ts TypeScript
const res = await fetch("https://www.summerengine.com/v1/jobs", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.SUMMER_TOKEN}`,
    "Content-Type": "application/json",
    "Idempotency-Key": crypto.randomUUID(),
    Prefer: "wait=60",
  },
  body: JSON.stringify({
    "model": "sound/sfx-v2",
    "input": {
      "text": "a sword hits a wooden shield",
      "durationSeconds": 2
    }
  }),
});
const { job } = await res.json();
console.log(job.state, job.id);
```

```python Python
import os, uuid, requests

res = requests.post(

    headers={

        "Idempotency-Key": str(uuid.uuid4()),
        "Prefer": "wait=60",

    json={"model": "sound/sfx-v2", "input": {"text": "a sword hits a wooden shield", "durationSeconds": 2}},
)
job = res.json()["job"]
print(job["state"], job["id"])
```

Three steps: get a key, check the price, make the model. At the end, `chest.glb` is in your folder and in your Summer library.

<Note>
Using a coding agent? Paste this and it does all three steps for you: `Use the Summer API for game assets. Read https://docs.summerengine.com/llms.txt and follow it to make "a stylized treasure chest, game prop" with 3d/default.`
</Note>

<Steps>
  <Step title="Get a key">
    Open [Summer Studio > Settings > API keys](https://summerengine.com/studio?tab=settings&section=api-keys), choose **Create key**, give it a name and a spend limit, and copy the key. Summer shows it once.

    Put it in your shell. The scripts below read it from there:

    ```bash
    export SUMMER_API_KEY=sk-summer-v1-...
    ```

    In a project, keep it in a `.env` file that your app loads and that is in `.gitignore`.

    An agent can also ask for a key itself: you get one link, check the code and choose **Allow**. See [Agents](/api/agents#get-a-key-from-your-agent).

    `3d/default` needs bought credits: add them at [Summer Studio > Credits](https://summerengine.com/studio/credits), no plan needed. With only a new account's welcome credits, use a model marked Free credits: Yes on the [models page](/api/models#3d-models) instead.
  </Step>
  <Step title="Check the price (free)">
    `POST /v1/estimate` takes the same body as the job and answers with its price. It charges nothing and needs no key.

    ```bash
    curl https://www.summerengine.com/v1/estimate \
      -H "Content-Type: application/json" \
      -d '{"model": "3d/default", "input": {"kind": "text-to-3d", "prompt": "a stylized treasure chest, game prop"}}'
    ```

    The answer holds `price` in US dollars as a decimal string, `atMost` (`true`: the most it can cost), a `breakdown`, and a `quoteId`. Add `"quoteId"` next to `"model"` in the job body and Summer never charges more than it quoted. The quote holds for 15 minutes.
  </Step>
  <Step title="Make the model and save the GLB">
    This starts the job, waits for it and downloads the file. A 3D model takes a few minutes.

    <CodeGroup>

    ```bash curl
    # Needs curl and jq.
    API=https://www.summerengine.com/v1
    AUTH="Authorization: Bearer $SUMMER_API_KEY"

    JOB=$(curl -s $API/jobs -H "$AUTH" -H "Content-Type: application/json" \
      -H "Idempotency-Key: $(uuidgen)" -H "Prefer: wait=60" \
      -d '{"model": "3d/default", "input": {"kind": "text-to-3d", "prompt": "a stylized treasure chest, game prop"}}')
    echo "$JOB" | jq -e .job > /dev/null || { echo "$JOB"; exit 1; }
    ID=$(echo "$JOB" | jq -r .job.id)

    while true; do
      JOB=$(curl -s "$API/jobs/$ID" -H "$AUTH")
      STATE=$(echo "$JOB" | jq -r .job.state)
      [ "$STATE" = queued ] || [ "$STATE" = running ] || break
      sleep "$(echo "$JOB" | jq -r '.job.pollAfterSeconds // 5')"
    done
    [ "$STATE" = done ] || { echo "$JOB"; exit 1; }

    URL=$(echo "$JOB" | jq -r '(.job.result.assets[0] // .job.result.asset // .job.result).fileUrl')
    curl -fsL "$URL" -o chest.glb && echo "Saved chest.glb"
    ```

    ```ts TypeScript
    // make-chest.ts. Run with Node 22: npx tsx make-chest.ts
    import { writeFile } from "node:fs/promises";

    const API = "https://www.summerengine.com/v1";
    const auth = { Authorization: `Bearer ${process.env.SUMMER_API_KEY}` };

    const res = await fetch(`${API}/jobs`, {
      method: "POST",
      headers: { ...auth, "Content-Type": "application/json", "Idempotency-Key": crypto.randomUUID(), Prefer: "wait=60" },
      body: JSON.stringify({
        model: "3d/default",
        input: { kind: "text-to-3d", prompt: "a stylized treasure chest, game prop" },
      }),
    });
    const started = await res.json();
    if (started.error) throw new Error(`${started.error.code}: ${started.error.message}`);
    let job = started.job;
    console.log(`Job ${job.id}, estimated ${job.estimatedPrice} USD`);

    while (job.state === "queued" || job.state === "running") {
      await new Promise((done) => setTimeout(done, (job.pollAfterSeconds ?? 5) * 1000));
      job = (await (await fetch(`${API}/jobs/${job.id}`, { headers: auth })).json()).job;
    }
    if (job.state !== "done") throw new Error(`The job ended ${job.state}: ${job.error?.message ?? ""}`);

    const asset = job.result.assets?.[0] ?? job.result.asset ?? job.result;
    const file = await fetch(asset.fileUrl);
    if (!file.ok) throw new Error(`Download failed: ${file.status}`);
    await writeFile("chest.glb", Buffer.from(await file.arrayBuffer()));
    console.log(`Saved chest.glb (Summer asset ${asset.assetId})`);
    ```

    ```python Python
    # make_chest.py. Needs: pip install requests
    import os, time, uuid, requests

    API = "https://www.summerengine.com/v1"
    auth = {"Authorization": f"Bearer {os.environ['SUMMER_API_KEY']}"}

    started = requests.post(
        f"{API}/jobs",
        headers={**auth, "Idempotency-Key": str(uuid.uuid4()), "Prefer": "wait=60"},
        json={
            "model": "3d/default",
            "input": {"kind": "text-to-3d", "prompt": "a stylized treasure chest, game prop"},
        },
    ).json()
    if "error" in started:
        raise SystemExit(f"{started['error']['code']}: {started['error']['message']}")
    job = started["job"]
    print(f"Job {job['id']}, estimated {job['estimatedPrice']} USD")

    while job["state"] in ("queued", "running"):
        time.sleep(job.get("pollAfterSeconds", 5))
        job = requests.get(f"{API}/jobs/{job['id']}", headers=auth).json()["job"]
    if job["state"] != "done":
        raise SystemExit(f"The job ended {job['state']}: {job.get('error')}")

    result = job["result"]
    asset = (result.get("assets") or [result.get("asset") or result])[0]
    file = requests.get(asset["fileUrl"])
    file.raise_for_status()
    with open("chest.glb", "wb") as f:
        f.write(file.content)
    print(f"Saved chest.glb (Summer asset {asset['assetId']})")
    ```

## What you get back

A finished job has `state: "done"` and a `result` with the asset id in your Summer library and a Summer file URL. Short jobs, such as an image or a voice line, already come back done from `POST /v1/jobs`, because `Prefer: wait=60` holds the answer for up to 60 seconds. Long jobs answer `running`: check `GET /v1/jobs/{id}` until they finish. See [Jobs](/api/jobs).

## Make it yours

- **Rig and animate it.** On a character, add `"rig": true` and `"animationNames": ["Idle", "Walk", "Run"]`. The model page shows what the rig adds to the price.
- **Start from a picture.** Send `"kind": "image-to-3d"` and an `imageUrl`.
- **Pick another model.** Swap `3d/default` for any id on the [models page](/api/models).
- **Use it in Summer Engine.** Your agent imports the asset by its id from your Summer library, or you drop the GLB into your project.

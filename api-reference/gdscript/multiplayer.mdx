### leave_session

```gdscript
func leave_session() -> SummerOperation
```

Cancels a pending join or releases the active scene binding and atomically clears current World, Player, and Session projections. It does not destroy a platform World. Joining a World is [`Summer.client.join()`](/api-reference/gdscript/client#join) with a [`SummerJoinTarget`](/api-reference/gdscript/types/join-target); this service exposes no join entry to scripts.

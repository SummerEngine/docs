Typed authoritative World lifecycle operations.

## Signals

### shutdown_notice_changed

```gdscript
signal shutdown_notice_changed(notice: SummerShutdownNotice)
```

The platform announces, revises, or cancels maintenance. A `null` notice means cancellation before final saving begins. During advance notice, finish game events or persist their phase. At the preparation boundary, native gameplay input and simulation stop; [`save_requested`](/api-reference/gdscript/authority/world#save_requested) and save operation completions continue. Serialize directly in that callback and use [`commit_save()`](/api-reference/gdscript/authority/world#commit_save) followed by [`finish_snapshot()`](/api-reference/gdscript/authority/world#finish_snapshot). Do not wait for a scene frame, timer, or unrelated deferred callback during final saving. The stop deadline remains binding if the game does not acknowledge. A restart restores the same logical World; it never implies a gameplay wipe or a promise that replacement is already ready.

### save_requested

```gdscript
signal save_requested(request_id: String, deadline_unix_msec: int)
```

The platform requests a coherent final save before its deadline. Commit first, then acknowledge using [`finish_snapshot()`](/api-reference/gdscript/authority/world#finish_snapshot). Process crashes cannot deliver this signal, so periodic saves are still required.

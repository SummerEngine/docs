**Class:** `SummerAuthorityMatch` · **Inherits:** RefCounted · **Access:** `Summer.authority.match`

Typed authoritative Match operations.

Authority-only facade for Match settlement and lifecycle operations. It resolves the trusted World binding internally; game code supplies immutable [`SummerSession`](/api-reference/gdscript/types/session) capabilities and never peer IDs, supervisor routes, credentials, or runtime-role checks.

### conclude

```gdscript
func conclude(outcomes: Dictionary[SummerSession, SummerAuthorityMatch.MatchOutcome], reason: String = "match_complete", rating_deltas: Dictionary[SummerSession, int] = {}) -> SummerMatchConclusionOperation
```

Commits one exact outcome for every trusted outcome-eligible participant and returns the typed durable settlement. Spectators, ineligible participants, raw identifiers, forged same-ID Sessions, and divergent retries are rejected.
`rating_deltas` reports the game's own rating movement for each player, within ±1000, on a queue declared with `"ratingSystemRef": "authority_v1"`; see [`SummerAuthorityRatings`](/api-reference/gdscript/authority/ratings). Such a queue requires a delta for every participant, and every other queue rejects any delta: the platform refuses the result with `invalid_request` and nothing is committed, so the authority may conclude again with corrected arguments. Keys must be Sessions named in `outcomes`.
On a queue that declares teams, the platform scores the sides matchmaking formed from each player's [`SummerParticipant.team`](/api-reference/gdscript/types/participant#team); the outcomes name players, never teams. Give every member of one team the same outcome.

### get_participant

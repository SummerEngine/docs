**Class:** `SummerAuthorityAnalytics` · **Inherits:** RefCounted · **Access:** `Summer.authority.analytics`

Captures creator events through the private Supervisor.

Use `Summer.authority.analytics.capture("wave_completed", {"wave": 3})` from a hosted authority. The Supervisor supplies the current Game, Build, World and runtime identity after checking its active lease. Events describe the authority runtime, not an individual player or an inferred Match. These are creator observations, distinct from reserved platform facts. No route, scope or credential is exposed to game code. Local emulators and older Supervisors do not provide analytics persistence.

## Methods

### capture

```gdscript
func capture(name: String, properties: Dictionary = {}) -> SummerOperation
```

Returns immediately and succeeds only after durable persistence or a persisted duplicate acknowledgment. Properties must be bounded JSON values; reserved platform event names cannot be emitted. At most 32 captures are pending. Submissions use a separate bounded transport lane so analytics cannot block admission or lifecycle traffic. A single attempt uses a 25-second deadline including queue time. Every public failure is nonretryable; an uncertain acknowledgment may already have persisted, and calling capture again creates a new event. An older Supervisor reports `not_configured`; quota denial reports `analytics_storage_limit_exceeded`. Closing the World cancels pending operations. Process exit may lose pending observations. Never make gameplay depend on analytics delivery.

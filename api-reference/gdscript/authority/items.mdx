**Class:** `SummerAuthorityItems` · **Inherits:** RefCounted · **Access:** `Summer.authority.items`

Authority items facade for verified-Session projections.

Reads the catalog-derived read-only item projection for one verified [`SummerSession`](/api-reference/gdscript/types/session) of the current Match. It accepts no user IDs, exposes no economy mutation, and fails closed for cross-Match, forged, reserved, or ended Sessions.

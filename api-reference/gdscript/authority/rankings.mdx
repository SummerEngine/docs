**Class:** `SummerAuthorityRankings` · **Inherits:** RefCounted · **Access:** `Summer.authority.rankings`

Trusted reads and versioned writes for Game-scoped rankings.

The current World authority can read and compare-and-set a score by stable player ID without a matchmaking Session. A write uses the version returned by [`get_score()`](/api-reference/gdscript/authority/rankings#get_score). On a version conflict, read and recompute. After a transport failure, read to determine whether the write committed before making another decision. Game code never handles the Supervisor credential.

### set_score

```gdscript
func set_score(ranking: String, player_id: String, expected_version: int, value: int, games: int) -> SummerRankingOperation
```

Compares `expected_version` and sets the absolute `value` and `games` atomically. A missing score has version zero. Values are bounded to ±1000000000000, games to 2147483647, and versions to safe integers. The expected version must be below 9007199254740991 so the next version remains representable. The Engine does not automatically retry a write.

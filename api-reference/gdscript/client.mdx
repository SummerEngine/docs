**Class:** `SummerClient` · **Inherits:** RefCounted

Role-scoped client SDK root.

This root exists only for a client execution context. Its identity remains stable while immutable context projections advance after admission or reconnect; authority operations are never attached.

## Methods

### join

```gdscript
func join(target: SummerJoinTarget) -> SummerJoinOperation
```

The one way into a World. The `target` names the placement provider (matchmaking queue, direct World, invite, follow, portal, resume, or local fixture); every provider returns the same [`SummerJoinOperation`](/api-reference/gdscript/types/join-operation) with the same progress, typed failures, [`SummerJoinOperation.world`](/api-reference/gdscript/types/join-operation#world) and [`SummerJoinOperation.session`](/api-reference/gdscript/types/join-operation#session). Only a queue target can emit [`SummerJoinOperation.acceptance_required`](/api-reference/gdscript/types/join-operation#acceptance_required).
After a hosted connection is lost, a new queue or World join first awaits confirmed removal of the previous Session, then starts the requested placement within the original join deadline. Canceling that pending join stops the new placement but does not undo the durable Session cleanup.

```gdscript
var op := Summer.client.join(SummerJoinTarget.world(world_id))
var joined: SummerResult = await op.get_result_or_completed_signal()
if joined.ok:
    enter_gameplay_with(op.world, op.session)
```

A provider this runtime cannot reach yet fails typed with `unsupported_placement`.

| Parameter | Type | Default |
|---|---|---|
| `target` | [`SummerJoinTarget`](/api-reference/gdscript/types/join-target) | required |

**Returns:** [`SummerJoinOperation`](/api-reference/gdscript/types/join-operation)

### leave

```gdscript
func leave() -> SummerOperation
```

Leaves the current World, or abandons a join still in flight, and clears the client transport.
During hosted matchmaking, await the returned operation before exiting the client. Success means the Player Host acknowledged cancellation or reported that the ticket was already terminal, including when ticket creation was still in flight. A Host failure or request deadline returns a failure; it does not prove the ticket was cancelled. Repeated calls share the pending leave and preserve its result until another join starts.
Leaving an established hosted World closes its local connection promptly, then succeeds only when the Player Host confirms removal of the exact Session through its authenticated completion event or a bounded recovery read. If proof is still unknown at the leave deadline, the result is retryable and retains that Session identity for retry. A local fixture World only clears its local connection. Calling [`SummerOperation.cancel()`](/api-reference/gdscript/types/operation#cancel) on a join only cancels that local operation; use [`leave()`](/api-reference/gdscript/client#leave) to await hosted cleanup.

**Returns:** [`SummerOperation`](/api-reference/gdscript/types/operation)

Returns at once. Wait for the result with `var result: SummerResult = await op.get_result_or_completed_signal()`; see [SummerOperation](/api-reference/gdscript/types/operation).

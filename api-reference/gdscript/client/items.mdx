**Class:** `SummerClientItems` · **Inherits:** RefCounted · **Access:** `Summer.client.items`

Read-only revisioned inventory projection for the current player.

Exposes the platform-owned inventory of the current authenticated player as a monotonic read-only projection. The engine owns paging and gap recovery; stale values never overwrite newer state, and no method mutates ownership, balances, or the ledger. Hosted inventory refresh requires an authenticated Player Host and the `player.items@1` execution grant, independently of matchmaking. An explicitly launched local-emulator client with a player persona instead reads the fixture inventory frozen at initialization. That synthetic projection shares ownership identities with the local authority; it does not grant platform items or enable store and checkout services. Ordinary local clients without that fixture cannot refresh inventory. A retained facade cannot follow a new authenticated binding after shutdown/reinitialization: acquire it again from the current client. Released facades expose empty projection values and refuse new operations.

**Host capabilities named here:** `player.items@1`

### is_projection_loaded

```gdscript
func is_projection_loaded() -> bool const
```

Whether this client binding has completed an initial inventory projection. False before the first successful refresh and after binding teardown; true for a successfully loaded empty inventory, even when [`as_of_event_sequence`](/api-reference/gdscript/client/items#as_of_event_sequence) is zero. Reads the SDK's existing projection state without fetching or caching anything. Loaded does not mean current or authorized: later refreshes and inventory events may change the projection, and authority still verifies equipment ownership. C# exposes `IsProjectionLoaded()`.

**Returns:** bool

### get_owned_items

```gdscript
func get_owned_items(definition_id: String = "") -> SummerInventoryItem[] const
```

Returns current items for which [`SummerInventoryItem.is_owned()`](/api-reference/gdscript/types/inventory-item#is_owned) is true, optionally filtered by an exact definition ID. An empty ID returns all owned items. Preserves the stable item identity order of [`items`](/api-reference/gdscript/client/items#items). The returned array is independent and its item values are immutable. This reads the current inventory projection without network requests; a purchase receipt alone never grants ownership.

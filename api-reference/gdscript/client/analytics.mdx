**Class:** `SummerClientAnalytics` · **Inherits:** RefCounted · **Access:** `Summer.client.analytics`

Captures creator game events through the private Player Host.

Use `Summer.client.analytics.capture("level_completed", {"level": 3})`. Events are untrusted creator observations, distinct from platform facts. The Host supplies the private player, game, build and analytics-session identity. No URL or credential is available to game code. An authenticated Host advertising analytics support is required.

## Methods

### capture

```gdscript
func capture(name: String, properties: Dictionary = {}) -> SummerOperation
```

Returns immediately. Completion succeeds after durable persistence (including an already-persisted retry). Properties must be JSON values; platform naming and property policies apply, and reserved platform event names cannot be emitted. At most 32 submissions are pending; excess calls fail with `capacity_exceeded`. A platform storage-quota rejection reports `analytics_storage_limit_exceeded` with retryable false. Capture results never recommend automatic recapture. One submission is made within the service deadline; automatic retries are disabled. An unavailable or timed-out result may already have persisted. Calling capture again creates a new event, so do not recapture the same action to recover an uncertain acknowledgment. Process exit may lose pending observations. Never make gameplay depend on analytics delivery.

**Class:** `SummerClientPlayerData` · **Inherits:** RefCounted · **Access:** `Summer.client.player_data`

Read-only view of this player's own public player data.

Reads the public slot the Game's hosted authority wrote for this player, for example to show a rank in the lobby before matchmaking. Clients cannot write player data, and the secret slot never reaches the client. Games without a hosted authority fail with `player_data_unavailable`.

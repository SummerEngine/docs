**Class:** `SummerClientChannels` · **Inherits:** RefCounted · **Access:** `Summer.client.channels`

Player chat channels bound to the current admitted World.

Obtain this facade from [`Summer.client.channels`](/api-reference/gdscript/client#channels). The authenticated Player Host supplies identity and membership. A reservation is insufficient; join the World before opening a channel. This client capability does not expose account DMs, arbitrary recipients, or authority-authored messages.

### open_world_channel

```gdscript
func open_world_channel(channel_key: String) -> SummerWorldChannelOpenOperation
```

Opens a channel for the current World. Keys contain 1 to 64 ASCII letters, digits, underscores, dots or hyphens, beginning with a letter or digit. The handle never retargets to another admission. Open completion makes the handle available; its initial authorized history arrives through [`SummerWorldChannel.history_changed`](/api-reference/gdscript/types/world-channel#history_changed).

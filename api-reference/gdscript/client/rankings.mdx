**Class:** `SummerClientRankings` · **Inherits:** RefCounted · **Access:** `Summer.client.rankings`

This player's Game-scoped ranking scores.

Reads a ranking declared by the active Game through the authenticated Player Host. It works in standalone games before any matchmaking Session exists. The caller can read only their own score and standing; leaderboard rows contain display names, not account IDs. Each method returns a typed operation whose result may be awaited.

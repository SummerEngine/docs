**Class:** `SummerClientRatings` · **Inherits:** RefCounted · **Access:** `Summer.client.ratings`

This player's own match results and committed account ratings.

Two facts converge here and game code never has to relay either. When the authority concludes a Match, the Engine delivers this Session's outcome as a [`SummerMatchResult`](/api-reference/gdscript/types/match-result) with a pending rating and emits [`match_result`](/api-reference/gdscript/client/ratings#match_result). When the platform commits the rating, the trusted Player Host delivers it privately to this player alone; the same result moves to committed and [`rating_committed`](/api-reference/gdscript/client/ratings#rating_committed) fires. Stale or replayed facts never overwrite newer state, and no other player's result or rating is ever visible here.
Recovery after a missed delivery is [`refresh()`](/api-reference/gdscript/client/ratings#refresh), a bounded read through the Player Host of the same `value`, `games`, `version` triple. Game code never calls the platform directly.

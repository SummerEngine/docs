**Class:** `SummerClientParty` · **Inherits:** RefCounted · **Access:** `Summer.client.party`

The player's Summer party as this Game sees it.

A Summer party belongs to the player's account and follows them across Games. This view shows its members, its leader, which members have this Game open, data this Game shares with the party, and whether the party is searching a queue in this Game. The trusted Summer app owns creating parties, invitations, kicking, leadership transfer and chat; [`show_invite_dialog()`](/api-reference/gdscript/client/party#show_invite_dialog) and [`show_party_dialog()`](/api-reference/gdscript/client/party#show_party_dialog) ask the app to present those screens. The Game never sees the party ID, invitations, chat, another Game's data, or which other Game a member is playing.
The view is a snapshot read through the Player Host whenever the party changes, when the event stream starts or resyncs, and on [`refresh()`](/api-reference/gdscript/client/party#refresh). Every signal is emitted after the snapshot is updated, once per real change. Getters return empty values outside a party and when [`is_available()`](/api-reference/gdscript/client/party#is_available) is `false`: in local play, for a guest, or when the Summer app does not offer parties.
To bring the party into a match, the leader joins [`SummerJoinTarget.party_queue()`](/api-reference/gdscript/types/join-target#party_queue); every other member follows by joining the same target when [`search_started`](/api-reference/gdscript/client/party#search_started) fires.

```gdscript
var party := Summer.client.party
party.search_started.connect(func(queue: StringName) -> void:
    if not party.is_leader():
        var result := await Summer.client.join(SummerJoinTarget.party_queue(queue)).completed
        if not result.is_ok():
            push_warning(result.message)
)

func _on_play_pressed(queue: StringName) -> void:
    if party.is_in_party():
        if party.is_leader():
            await Summer.client.join(SummerJoinTarget.party_queue(queue)).completed
    else:
        await Summer.client.join(SummerJoinTarget.queue(queue)).completed
```

Games typically disable Play for members, show each member's [`SummerPartyMember.in_game`](/api-reference/gdscript/types/party-member#in_game), and use [`set_data()`](/api-reference/gdscript/client/party#set_data) so members see the leader's selection.

### set_data

```gdscript
func set_data(key: String, value: String) -> SummerOperation
```

Sets this Game's party data for `key`; an empty `value` deletes the key. Only the leader can set party data. Keys are 1 to 32 characters of `a-z`, `0-9`, `_`, `.` and `-`; values are at most 256 UTF-8 bytes of text without control characters and pass the Summer chat text filter; a party holds at most 16 keys per Game.
The Engine refuses before any network request with `not_party_leader` for a member, `party_not_found` outside a party, or `invalid_argument` for a key, value or key count outside these limits. The platform remains the authority and may still refuse with the same codes, or with `text_not_allowed` when the text filter rejects the value. Writes are applied in call order and fenced by the party version; if the party changed underneath a write, the Engine re-reads it and sends the write once more before failing with retryable `party_version_conflict`. On success, [`data_changed`](/api-reference/gdscript/client/party#data_changed) has already fired.

### show_invite_dialog

```gdscript
func show_invite_dialog() -> SummerOperation
```

Asks the Summer app to present its friend invite sheet over the game. The app creates a party first when the player has none. The operation completes when the app's presenter answers. The Summer app answers as soon as the sheet is on screen, not when the player closes it, so the game keeps running and receives party changes while the sheet is open. It fails with `ui_unavailable` when the app cannot present the sheet right now and nothing is shown, and with `capability_unavailable` when [`is_available()`](/api-reference/gdscript/client/party#is_available) is `false`. Invitations sent from the sheet reach the game only as later party changes.

**Returns:** [`SummerOperation`](/api-reference/gdscript/types/operation)

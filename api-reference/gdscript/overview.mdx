**Class:** `SummerRuntime` · **Inherits:** Object

Engine-owned Summer context and service singleton registered as `Summer`.

Publishes immutable Game, Build, Player, World, and Session projections and owns [`multiplayer`](/api-reference/gdscript/overview#multiplayer). [`initialize()`](/api-reference/gdscript/overview#initialize) and [`shutdown()`](/api-reference/gdscript/overview#shutdown) are main-thread, concurrent-idempotent operations; internal state and atomic context changes happen before operation completion. Tickets, credentials, raw launch state, peers, admission verdicts, hosted ports, and runtime-role selection are not exposed. Ordinary gameplay should use runtime-routed behavior callbacks rather than server/client role queries.

### initialize

```gdscript
func initialize(game_id: String = "") -> SummerOperation
```

Starts initialization using the trusted Game identity supplied by the Summer Host or hosted authority launch. Omit `game_id` for a portable build. When supplied, it asserts the expected identity and never grants authorization or overrides the launch context. With no online launch or Host, an omitted ID creates a project-scoped synthetic local identity; a supplied ID preserves that explicit local namespace. Read the resolved identity with [`get_game()`](/api-reference/gdscript/overview#get_game).
A mismatch returns `&"game_identity_mismatch"` without publishing partial context. An incomplete/refused trusted context returns `&"trusted_launch_unavailable"` and never falls back to local play. Successful hosted authority initialization atomically publishes immutable Game, Build, and World projections without inventing a Player or Session.
Concurrent callers that omit the ID or assert the same resolved ID share one pending operation. Ready replay preserves the current context. A conflicting in-flight or ready ID returns `&"identity_conflict"`. Successful completion publishes [`STATE_READY`](/api-reference/gdscript/overview#state_ready). Cancellation restores the stable lifecycle state that preceded this initialization attempt.

| Parameter | Type | Default |
|---|---|---|
| `game_id` | String | `""` |

**Returns:** [`SummerOperation`](/api-reference/gdscript/types/operation)

Returns at once. Wait for the result with `var result: SummerResult = await op.get_result_or_completed_signal()`; see [SummerOperation](/api-reference/gdscript/types/operation).

### How calls work

Every call that talks to Summer returns a [`SummerOperation`](/api-reference/gdscript/types/operation) at once and finishes later on the main thread. Await its result:

```gdscript
var op := Summer.client.analytics.capture("level_completed", {"level": 3})
var result: SummerResult = await op.get_result_or_completed_signal()
if not result.ok:
    push_warning(result.message)
```

`Summer.client` exists only in the player's game and `Summer.authority` only on your game's server. The other one is `null`. Check readiness before you offer a feature: many services have `is_available()` or a `check_*_readiness()` method.

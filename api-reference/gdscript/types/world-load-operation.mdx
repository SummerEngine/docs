**Class:** `SummerWorldLoadOperation` · **Inherits:** [`SummerOperation`](/api-reference/gdscript/types/operation)

Loads the current World save through its trusted owner.

A successful result exposes a validated save, including schema and Build identity. Failure preserves admission closure. This operation does not deserialize or run game code.

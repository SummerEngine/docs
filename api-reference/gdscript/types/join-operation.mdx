**Class:** `SummerJoinOperation` · **Inherits:** [`SummerOperation`](/api-reference/gdscript/types/operation)

The one operation every way into a World returns.

Returned by [`Summer.client.join()`](/api-reference/gdscript/client#join) for every [`SummerJoinTarget`](/api-reference/gdscript/types/join-target). Publishes its immutable [`world`](/api-reference/gdscript/types/join-operation#world) and [`session`](/api-reference/gdscript/types/join-operation#session) only after placement, signed launch verification, transport activation, compatibility, and authority admission all succeed. Progress is the same sanitized [`SummerJoinProgress`](/api-reference/gdscript/types/join-progress) for every provider; failures are the same typed codes. [`pending_proposal`](/api-reference/gdscript/types/join-operation#pending_proposal) is only ever set for a queue target.

## Signals

### acceptance_required

```gdscript
signal acceptance_required(proposal: SummerMatchmakingProposal)
```

A matchmaking proposal is pending and requires an explicit decision through [`SummerMatchmakingProposal.accept()`](/api-reference/gdscript/types/matchmaking-proposal#accept) or [`SummerMatchmakingProposal.decline()`](/api-reference/gdscript/types/matchmaking-proposal#decline). The engine never decides on the game's behalf; games that want automatic behavior connect this signal directly to [`SummerMatchmakingProposal.accept()`](/api-reference/gdscript/types/matchmaking-proposal#accept). Only a queue target emits it.

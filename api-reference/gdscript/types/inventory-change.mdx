**Class:** `SummerInventoryChange` · **Inherits:** RefCounted

One immutable inventory projection change.

Describes one replacement or removal applied to an inventory projection. Changes are lossy freshness hints over the monotonic projection, never ownership truth; a missed change triggers an engine-owned refresh. Replacements carry the already-applied [`item`](/api-reference/gdscript/types/inventory-change#item); removals carry only identity and sequence.

**Class:** `SummerAuthorityLeaseStatus` · **Inherits:** RefCounted

Read-only projection of authority lease health.

Contains no credential or renewal route. A hosted authority reads its native process ownership decision. A retained reference reflects later lease renewals and loss; game code cannot renew the lease or revive a fenced authority.

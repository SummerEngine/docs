**Class:** `SummerParticipant` · **Inherits:** RefCounted

Verified Session role, outcome eligibility and team in one Match.

The Session object itself is the addressing capability. Same-text IDs on a different object do not match this participant. The authority reads the participant for an admitted Session with `Summer.authority.match.get_participant(session)`.

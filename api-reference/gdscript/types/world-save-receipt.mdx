**Class:** `SummerWorldSaveReceipt` · **Inherits:** RefCounted

Immutable accepted save revision.

Returned by a successful World save commit. Receipt identity belongs to one World runtime. A successful upload alone is not a receipt. Cancellation or timeout cannot prove that a save was not committed.

**Class:** `SummerLeaderboardOperation` · **Inherits:** [`SummerOperation`](/api-reference/gdscript/types/operation)

Reads a rated queue's top-50 leaderboard.

Completes with up to 50 [`SummerLeaderboardEntry`](/api-reference/gdscript/types/leaderboard-entry) rows in rank order: highest rating first, then whoever reached it first. Only players with a settled rated Match appear. The members are empty until the operation succeeds. A queue that keeps no rating fails with `rating_unavailable`.

```gdscript
var board := Summer.client.ratings.leaderboard(&"dungeon")
await board.get_result_or_completed_signal()
for entry in board.entries:
print("%d. %s %d%s" % [entry.rank, entry.display_name, entry.value, " (you)" if entry.you else ""])
```

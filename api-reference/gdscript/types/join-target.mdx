**Class:** `SummerJoinTarget` · **Inherits:** RefCounted

Which placement provider brings this player into a World.

The single argument of [`Summer.client.join()`](/api-reference/gdscript/client#join). A target is an immutable statement of intent built with one of the static constructors: [`queue()`](/api-reference/gdscript/types/join-target#queue) for solo matchmaking, [`party_queue()`](/api-reference/gdscript/types/join-target#party_queue) to queue with the account party, [`world()`](/api-reference/gdscript/types/join-target#world) for a direct or open World join, [`invite()`](/api-reference/gdscript/types/join-target#invite) for a private code, [`follow()`](/api-reference/gdscript/types/join-target#follow) for a party or player, [`portal()`](/api-reference/gdscript/types/join-target#portal) for an authority-issued transfer, [`resume()`](/api-reference/gdscript/types/join-target#resume) for a reconnect, and [`local()`](/api-reference/gdscript/types/join-target#local) for the in-process development fixture.
Every target yields the same [`SummerJoinOperation`](/api-reference/gdscript/types/join-operation), the same progress stages, the same typed failures, and the same [`SummerWorld`](/api-reference/gdscript/types/world) and [`SummerSession`](/api-reference/gdscript/types/session) after admission. Only queue targets can ever raise [`SummerJoinOperation.acceptance_required`](/api-reference/gdscript/types/join-operation#acceptance_required); a game that never matchmakes never sees a proposal or a Match.
Targets carry safe intent only. They never contain tickets, tokens, endpoints, or platform identifiers.

### party_queue

```gdscript
func party_queue(queue: StringName, request: SummerMatchmakingRequest = null) -> SummerJoinTarget static
```

Enter the named queue together with the player's current Summer party. The same target serves every member. When the leader joins it, the party search starts; every member must have this Game open with a compatible Build, otherwise the join fails with retryable `party_member_offline`. When another member joins it, they attach to the party's search in progress for the same queue and receive their own Session in the same match; with no such search it fails with retryable `party_not_searching`. Members typically join when [`Summer.client.party.search_started`](/api-reference/gdscript/client/party#search_started) fires. Outside a party it fails with `party_not_found`.
Every party member goes through the same search, proposal, cancellation and admission lifecycle as [`queue()`](/api-reference/gdscript/types/join-target#queue), and receives the ordinary join result. Party membership and private chat persist across Games and remain owned by the Summer account; the game never receives the party's private chat history or credentials. Requires a Host advertising `find_party_session`; unavailable Hosts fail explicitly. Local play has no account party and fails with `capability_unavailable`.

```gdscript
var party := Summer.client.party
party.search_started.connect(func(queue: StringName) -> void:
    if not party.is_leader():
        var result := await Summer.client.join(SummerJoinTarget.party_queue(queue)).completed
        if not result.is_ok():
            push_warning(result.message)
)
```

### queue

```gdscript
func queue(queue: StringName, request: SummerMatchmakingRequest = null) -> SummerJoinTarget static
```

Enter through matchmaking on the named queue. The optional `request` only tunes region preferences and the bounded search lifetime; a request naming a different queue fails the join with `invalid_argument`. When the queue declares acceptance, the operation pauses at [`SummerJoinProgress.STAGE_PROPOSED`](/api-reference/gdscript/types/join-progress#stage_proposed) and emits [`SummerJoinOperation.acceptance_required`](/api-reference/gdscript/types/join-operation#acceptance_required).

**Class:** `SummerPlayerDataCommitOperation` · **Inherits:** [`SummerOperation`](/api-reference/gdscript/types/operation)

Writes one slot of a player's data.

A failure code is one of `player_data_invalid`, `player_data_too_large`, `player_data_unsupported_type`, `player_data_session_invalid`, `player_data_superseded`, `player_data_save_id_conflict`, `runtime_fenced`, `rate_limited`, `player_data_unavailable` or `operation_in_progress`. When [`SummerResult.retryable`](/api-reference/gdscript/types/result#retryable) is set, commit again with the same save ID.

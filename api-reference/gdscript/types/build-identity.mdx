**Class:** `SummerBuildIdentity` · **Inherits:** RefCounted

Immutable Build and compatibility identity selected by Summer.

Represents immutable Build identity known to Summer. A signed native launch currently supplies the Build ID and exact artifact digest; protocol, synchronization, and prediction compatibility remain empty until a verified manifest or handshake supplies them. Synthetic local development uses explicit local compatibility placeholders. Callers must not interpret an empty compatibility field as compatible.

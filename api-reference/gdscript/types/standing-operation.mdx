**Class:** `SummerStandingOperation` · **Inherits:** [`SummerOperation`](/api-reference/gdscript/types/operation)

Reads the caller's own place in a rated queue.

Completes with the caller's rating, how many players are rated in the queue, their percentile once rated, and their leaderboard rank when it is within the top 1000. Players are ordered exactly as on the leaderboard. The members are empty until the operation succeeds.

```gdscript
var standing := Summer.client.ratings.standing(&"dungeon")
await standing.get_result_or_completed_signal()
if standing.rank > 0:
label.text = "#%d of %d" % [standing.rank, standing.players]
elif standing.rated:
label.text = "Top %.1f%%" % (100.0 - standing.percentile)
```

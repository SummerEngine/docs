**Class:** `SummerFriend` · **Inherits:** RefCounted

One of the player's Summer friends, as this Game may see them.

An immutable view of one friend in one read of [`Summer.client.friends`](/api-reference/gdscript/client#friends). A later read that changes this friend replaces the object, so key UI by [`user_id`](/api-reference/gdscript/types/friend#user_id) rather than holding the object. [`user_id`](/api-reference/gdscript/types/friend#user_id) and [`display_name`](/api-reference/gdscript/types/friend#display_name) match the identity the Game sees for the same player in a [`SummerSession`](/api-reference/gdscript/types/session).

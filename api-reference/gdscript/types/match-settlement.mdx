**Class:** `SummerMatchSettlement` · **Inherits:** RefCounted

Immutable, complete server-visible match settlement.

Returned to the authoritative game only after Summer Platform commits the match result. The authority deliberately transforms this value into separately declared private or public projections before completing the World.

**Class:** `SummerSession` · **Inherits:** RefCounted

Immutable Player association with a Summer World.

A Session records allocation and presence, not transport connection truth. The runtime publishes a new immutable projection for a transition; game code cannot assign Session, Player, World, peer, or entity identity.

**Class:** `SummerExecutionDescriptor` · **Inherits:** RefCounted

Immutable role, topology, artifact profile, and capabilities selected before execution.

The descriptor is observational context, not a runtime role switch. Artifact composition removes forbidden APIs and source domains; game code cannot mutate the descriptor to acquire authority or trigger a local/hosted fallback.

**Class:** `SummerJoinProgress` · **Inherits:** RefCounted

Immutable sanitized join progress, identical for every placement provider.

Exposes coarse UX state without tickets, endpoints, launch carriers, join grants, bearer tokens, or platform routes. The same stages apply whether the player entered through matchmaking, a direct World join, an invite, a follow, a portal, or a resume.

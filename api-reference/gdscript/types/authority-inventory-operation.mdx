One allowlisted authority inventory read for one verified Session.

Reads the catalog-derived item projection for one verified [`SummerSession`](/api-reference/gdscript/types/session) belonging to the current Match. Authority code never supplies a user ID; cross-Match and ended-Session requests fail closed. Items are exposed only after successful completion.

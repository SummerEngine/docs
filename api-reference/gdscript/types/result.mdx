**Class:** `SummerResult` · **Inherits:** RefCounted

Immutable structured result returned by Summer runtime operations.

Carries an allowlisted stable status code, bounded user-safe message, retryability flag, and read-only detail projection across native, GDScript, and C# boundaries. Detail dictionaries have bounded depth, node count, collection size, and strings; accept only finite recursively immutable value Variants; and reject object, resource, RID, callable, and signal references. Instances are created by the engine; scripts cannot construct or mutate them.

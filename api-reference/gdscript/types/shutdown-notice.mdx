**Class:** `SummerShutdownNotice` · **Inherits:** RefCounted

Immutable platform advance notice for a World shutdown.

The platform owns the reason, schedule and disposition. Game code prepares coherent state through ordinary save APIs and does not renew a keepalive lease. Native execution uses conservative owner-time projection, so changing the game's system clock cannot extend permission. A retained notice stays immutable after updates or cancellation; read the authority World's current notice for live state. Notice cannot be guaranteed for crashes or emergencies.

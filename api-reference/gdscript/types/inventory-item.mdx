**Class:** `SummerInventoryItem` · **Inherits:** RefCounted

One immutable revisioned platform item projection.

An immutable canonical owned-item projection with identity, definition, presentation, rights, cosmetic and passport data. Use [`get_owned_item_id()`](/api-reference/gdscript/types/inventory-item#get_owned_item_id) to correlate the owned-item identity reported by a committed purchase. The same resource supports authority inventory; identity aliases describe the same item and never create a second ownership source. Optional presentation and passport values may be empty when absent.

### is_outcome_unknown

```gdscript
func is_outcome_unknown() -> bool const
```

True when this request may have reached the backend and no authoritative terminal outcome or definite no-effect refusal is known. This does not assert backend acceptance. Canceling this local handle leaves uncertainty unchanged; terminal status delivery clears it even for a canceled handle. Binding teardown completes with checkout_outcome_unknown and preserves this flag. A new request_checkout call always creates a fresh purchase action; never automatically retry an unknown outcome with a new call.

**Returns:** bool

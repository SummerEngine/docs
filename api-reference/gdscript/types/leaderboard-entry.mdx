**Class:** `SummerLeaderboardEntry` · **Inherits:** RefCounted

One ranked player on a queue's leaderboard.

A leaderboard names players by their profile display name only, never by account. Equal ratings still get distinct ranks: whoever reached the rating first ranks higher.

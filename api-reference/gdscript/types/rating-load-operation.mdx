**Class:** `SummerRatingLoadOperation` · **Inherits:** [`SummerOperation`](/api-reference/gdscript/types/operation)

Reads one player's queue rating for the authority.

Completes with the current rating of the player behind a [`SummerSession`](/api-reference/gdscript/types/session), in the queue that admitted that Session. The members are empty or `null` until the operation succeeds. A Session whose queue keeps no rating fails with `rating_unavailable`.

## Properties

| Property | Type | Access | Description |
|---|---|---|---|
| <a id="queue" />`queue` | StringName | read-only, `get_queue()` | The queue that admitted the Session. |
| <a id="rating" />`rating` | [`SummerRatingSnapshot`](/api-reference/gdscript/types/rating-snapshot) | read-only, `get_rating()` | The player's current rating in `queue`. An unrated player reads the queue's `initialRating` (1200 unless the queue declares one) with `SummerRatingSnapshot.games` and `SummerRatingSnapshot.version` at `0`. |
| <a id="system" />`system` | StringName | read-only, `get_system()` | The queue's rating system, such as `authority_v1`. |

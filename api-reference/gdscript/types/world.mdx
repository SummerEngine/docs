**Class:** `SummerWorld` · **Inherits:** RefCounted

Immutable projection of the active Summer World.

A World is the stable runtime simulation aggregate. It references the immutable Game and Build but exposes no Pod, namespace, hosted port, supervisor path, transport peer, or runtime-role setter.

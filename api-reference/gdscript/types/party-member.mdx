**Class:** `SummerPartyMember` · **Inherits:** RefCounted

One member of the player's Summer party, as this Game sees them.

An immutable view of one member in one party snapshot from [`Summer.client.party`](/api-reference/gdscript/client#party). A later snapshot that changes this member replaces the object, so key UI by [`user_id`](/api-reference/gdscript/types/party-member#user_id) rather than holding the object. [`user_id`](/api-reference/gdscript/types/party-member#user_id) and [`display_name`](/api-reference/gdscript/types/party-member#display_name) match the identity the Game sees for the same player in a [`SummerSession`](/api-reference/gdscript/types/session). Data belongs to this Game only.

Summer is the game engine built for AI. Every Summer API uses your Summer account. For the MCP and the CLI you never paste a key: you sign in once in the browser, and the tool keeps the token. The [Summer API](/api/overview) for game assets uses a key with its own spend limit.

## Which sign-in each API uses

| API | How it signs in |
|---|---|
| Hosted MCP (`https://mcp.summerengine.com/mcp`) | OAuth. Your agent opens the Summer sign-in page once. Sign in and choose **Allow**. |
| `summer` CLI and the local MCP (`summer mcp`) | `summer login` opens your browser once. It signs in your Summer account, then the store, publishing and Grow tools. |
| Engine tools (scenes, scripts, play) | No sign-in. Summer Engine writes a local token to `~/.summer/api-token` when it starts, and the local MCP reads it. |
| [HTTP API](/api-reference/http/overview) (`api.summer.games`) | A bearer token from the same OAuth sign-in: `summer login --store`, or the Summer connector in an AI app. |
| [Summer API](/api/overview) (`www.summerengine.com/v1`) | `Authorization: Bearer $SUMMER_API_KEY`. Make a key in **Settings > API keys**, or let your agent ask for one. See [Keys and limits](/api/keys). |

## Files and variables

| Path or variable | What it holds |
|---|---|
| `~/.summer/auth-token` | Your Summer account token, from `summer login` |
| `~/.summer/oauth-token`, `~/.summer/oauth-client` | The store sign-in, from `summer login`. It renews itself. |
| `~/.summer/api-token` | The local engine token. The engine writes it on every start. |
| `SUMMER_TOKEN` | A Summer account token for scripts and CI. It wins over `~/.summer/auth-token`. `summer logout` does not clear it. |

`summer whoami` shows who is signed in. `summer logout` removes the saved tokens.

## When sign-in is missing

An operation that needs a sign-in answers with the error code `not_signed_in` and one next step. On the hosted MCP, your agent opens the sign-in page again. Locally, run `npx -y summer-engine@latest login`. All codes: [How Summer answers](/api-reference/mcp#errors).

Describe the game you want, and an agent builds it: scenes, code, art and sound. It plays the game to check its own work. Every Summer game can go online with the Summer SDK: Summer runs the servers, matchmaking, saves and store, and your agent publishes the game on [Summer Games](https://summer.games).

## Using a coding agent?

Paste this into Claude Code, Codex, Cursor or any other agent. It installs what is missing and opens a first game.

<Prompt description="**Set up Summer and start a game.** Your agent checks your computer, installs Summer and opens a starter project.">
Install Summer Engine and let's make a game. Follow https://docs.summerengine.com/quickstarts/coding-agent.md: check what I already have installed, install whatever is missing, and open a starter project so we can start building.
</Prompt>

Or run the setup yourself:

```bash
npx -y summer-engine@latest setup claude-code --yes
```

Use `codex`, `cursor` or [your agent's id](/mcp/setup#every-agent) in place of `claude-code`. On Windows PowerShell, type `npx.cmd` in place of `npx`.

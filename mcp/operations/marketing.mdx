### apply

`marketing.apply`: **Apply for a growth service**

Send an application for a service Summer runs for a game (promotion, paid ads, email outreach, creator introductions, featured placement, A/B test). Never a purchase; the Summer team replies by email. Runs when the person allows Contact people; otherwise needs_approval.

| | |
|---|---|
| **MCP** | `summer_call` with `"op": "marketing.apply"` |
| **CLI** | `summer marketing apply` |
| **Runs** | On Summer's servers: the hosted MCP, or the npm MCP after `summer login`. Needs your Summer sign-in. |
| **Effect** | Changes your own drafts, files or settings. Nobody else sees it yet. |
| **Asks you first** | Yes: **Contact people** is off by default in Agent permissions. |
| **3.x names** | `summer_grow_apply` |

**Inputs:**

| Input | Type | Required | Description |

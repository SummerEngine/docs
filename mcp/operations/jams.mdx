### enter

`jams.enter`: **Enter a game jam**

Ask the person to enter one of their games in an open Summer Games Jam, or to refresh its entry after the page or builds changed. Entering agrees to the jam rules and terms. Answers a link for them to confirm. Next: jobs.wait.

| | |
|---|---|
| **MCP** | `summer_call` with `"op": "jams.enter"` |
| **CLI** | `summer jams enter` |
| **Runs** | On Summer's servers: the hosted MCP, or the npm MCP after `summer login`. Needs your Summer sign-in. |
| **Effect** | Changes your own drafts, files or settings. Nobody else sees it yet. |
| **Asks you first** | Always. You approve it in Studio; an agent can never skip this. |
| **3.x names** | `summer_store_enter_jam` |

**Inputs:**

| Input | Type | Required | Description |
|---|---|---|---|
| `gameId` | string | Yes | From games.list. |
| `jamSlug` | string | Yes | A jam slug from jams.list, e.g. light. |
| `dryRun` | boolean | No | Check and describe the call without doing it: nothing changes, nothing is spent. |
| `idempotencyKey` | string | No | Retry key. Reuse it only to retry the identical request, so it never happens twice. Length 1 to 128. |

### withdraw

| **Asks you first** | No: **Make and build** is on by default in Agent permissions. When it is off, your agent asks you first. |

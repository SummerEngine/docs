### propose_items

`economy.propose_items`: **Propose item changes to the owner**

<Note>Preview: search finds it and `summer_call` runs it. It may still change.</Note>

Send a game's item plan (items by item key) to its owner. Answers needs_approval with a link; on Approve, Studio creates or revises each item, sets its price and submits it for Summer's review. Never publishes. At most 50 items.

| | |
|---|---|
| **MCP** | `summer_call` with `"op": "economy.propose_items"` |
| **CLI** | `summer economy propose-items` |
| **Runs** | On Summer's servers: the hosted MCP, or the npm MCP after `summer login`. Needs your Summer sign-in. |
| **Effect** | Changes your own drafts, files or settings. Nobody else sees it yet. |
| **Asks you first** | Always. You approve it in Studio; an agent can never skip this. |
| **Retry key** | Required: send a new `idempotencyKey` for each new request, the same one only to retry it. |

### sync_items

`economy.sync_items`: **Sync items**

<Note>Preview: search finds it and `summer_call` runs it. It may still change.</Note>

Sync summer.items.json to the store game by item slug - a plan, then the owner's approval in Studio. Needs the store sign-in (summer login --store).

| | |
|---|---|
| **MCP** | `summer_sync_items` in the npm MCP |
| **CLI** | `summer economy sync-items` |
| **Runs** | On your computer, in the `summer-engine` npm package. |
| **Effect** | Publishes: makes something public or live. |
| **Asks you first** | Yes, every time: it first answers with what it will do, and runs only with `confirm: true` after you say yes. |
| **3.x names** | `summer_sync_items` |

**Inputs:**

| Input | Type | Required | Description |
|---|---|---|---|
| `gameId` | string | No | The store game id on this gateway (from games.list). Staging and production games have different ids. Without it the call fails with game_required and lists your store games. Switching between staging and production takes SUMMER_GATEWAY_URL and SUMMER_MCP_RESOURCE_URL, then "summer login --store --force" (one store sign-in per machine). |
| `project` | string | No | Project folder with project.godot and summer.items.json. Defaults to the MCP's bound project, then the working directory. |
| `file` | string | No | The items file, relative to the project. Default summer.items.json. |
| `slugs` | string[] | No | Only these items (their slugs); the rest of the file is left out of the plan. Confirm a plan of more than 50 changed items one batch (from batches) at a time. |
| `confirm` | boolean | No | Set true only after the user approves the plan. Default `false`. |

### cancel

`jobs.cancel`: **Cancel a job**

Stop one of the person's jobs that has not finished: a plan agent request, a cloud build, or a publish request still waiting for the owner (its link stops working). Work already saved stays. Returns the job. Next: jobs.list.

| | |
|---|---|
| **MCP** | `summer_call` with `"op": "jobs.cancel"` |
| **CLI** | `summer jobs cancel` |
| **Runs** | On Summer's servers: the hosted MCP, or the npm MCP after `summer login`. Needs your Summer sign-in. |
| **Effect** | Changes your own drafts, files or settings. Nobody else sees it yet. |
| **Asks you first** | No: **Make and build** is on by default in Agent permissions. When it is off, your agent asks you first. |
| **3.x names** | `summer_board_agent_cancel`, `summer_board_build_cancel` |

| Input | Type | Required | Description |

| `idempotencyKey` | string | No | Retry key. Reuse it only to retry the identical request, so it never happens twice. Length 1 to 128. |

Publish the store page with a build and price: live once the automatic checks pass, never waiting on staff. Publishes now (a job) when the person's Agent permissions allow; else answers the owner's approval link. Needs an idempotencyKey. Next: jobs.wait, then store.status.

| **Asks you first** | Yes, for now: Summer Games still asks the game's owner first. Soon it follows **Publish** in Agent permissions (on by default). |
| **Retry key** | Required: send a new `idempotencyKey` for each new request, the same one only to retry it. |

### upload_complete

`store.upload_complete`: **Finish a store upload**

Finish a store upload after every part is PUT: Summer seals it and checks it. Answers a job while it checks (jobs.wait), or the finished status. Safe to call again. On a live game only the owner may finish a web build or download.

| | |
|---|---|
| **MCP** | `summer_call` with `"op": "store.upload_complete"` |
| **CLI** | `summer store upload-complete` |
| **Runs** | On Summer's servers: the hosted MCP, or the npm MCP after `summer login`. Needs your Summer sign-in. |
| **Effect** | Changes your own drafts, files or settings. Nobody else sees it yet. |
| **Asks you first** | No: **Make and build** is on by default in Agent permissions. When it is off, your agent asks you first. |
| **Long work** | Answers with a job at once. Wait with `jobs.wait`. |
| **3.x names** | `summer_build_complete_upload`, `summer_store_version_complete` |

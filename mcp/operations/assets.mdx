### upscale

`assets.upscale`: **Recreate a slice in high resolution**

Redraw one sliced item (from assets.slice_sheet) at about 1024 pixels with a transparent background, keeping its look; UI items use a model made for crisp edges and text. Returns the new image URL and size. Spends their credits. Next: assets.save_tileset.

| | |
|---|---|
| **MCP** | `summer_call` with `"op": "assets.upscale"` |
| **CLI** | `summer assets upscale` |
| **Runs** | On Summer's servers: the hosted MCP, or the npm MCP after `summer login`. Needs your Summer sign-in. |
| **Effect** | Spends your credits. |
| **Asks you first** | No: **Spend credits** is on by default in Agent permissions. When it is off, your agent asks you first. |

**Inputs:**

| Input | Type | Required | Description |
|---|---|---|---|
| `url` | string | Yes | The slice image URL. Length 0 to 2048. |
| `name` | string | Yes | The slice name, e.g. wooden_crate. Length 1 to 80. |
| `category` | "character" \| "terrain" \| "nature" \| "lighting" \| "water" \| "decorative" \| "buildings" \| "ui" \| "vfx" | No | ui runs the model made for interface pieces. |
| `dryRun` | boolean | No | Check and describe the call without doing it: nothing changes, nothing is spent. |
| `idempotencyKey` | string | No | Retry key. Reuse it only to retry the identical request, so it never happens twice. Length 1 to 128. |

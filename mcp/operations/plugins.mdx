### search

`plugins.search`: **Find plugins**

Find add-ons for a desktop project in Summer's plugin catalog by words, category or tier: name, what it does, its tier and how well agents work with it. Next: the Summer Engine plugin tools to add one.

| | |
|---|---|
| **MCP** | `summer_call` with `"op": "plugins.search"` |
| **CLI** | `summer plugins search` |
| **Runs** | On Summer's servers: the hosted MCP, or the npm MCP after `summer login`. Needs your Summer sign-in. |
| **Effect** | Reads only. Changes nothing. |
| **Asks you first** | No. It changes nothing. |

**Inputs:**

| Input | Type | Required | Description |
|---|---|---|---|
| `query` | string | No | What the plugin should do: "steam achievements", "dialogue". Length 0 to 200. |
| `category` | string | No | Length 0 to 80. |
| `tier` | "summer-verified" \| "curated-godot" \| "godot-assetlib" | No |  |
| `limit` | integer | No | Default `10`. Range 1 to 50. |

### suggest

`plugins.suggest`: **Suggest a plugin to Summer**

Ask the person to send the Summer team a plugin to review for the catalog: its link, why, and what project it fits. Returns a link; nothing is sent until they confirm. Next: jobs.wait.

| | |
|---|---|
| **MCP** | `summer_call` with `"op": "plugins.suggest"` |
| **CLI** | `summer plugins suggest` |
| **Runs** | On Summer's servers: the hosted MCP, or the npm MCP after `summer login`. Needs your Summer sign-in. |
| **Effect** | Changes your own drafts, files or settings. Nobody else sees it yet. |
| **Asks you first** | Yes: **Contact people** is off by default in Agent permissions. |

**Inputs:**

| Input | Type | Required | Description |
|---|---|---|---|
| `pluginUrl` | string | Yes | The plugin's page or repository. Length 0 to 2048. |
| `reason` | string | Yes | Why it should be in the catalog. Length 1 to 4000. |
| `projectKind` | string | No | The kind of project it fits. Length 0 to 240. |
| `dryRun` | boolean | No | Check and describe the call without doing it: nothing changes, nothing is spent. |
| `idempotencyKey` | string | No | Retry key. Reuse it only to retry the identical request, so it never happens twice. Length 1 to 128. |

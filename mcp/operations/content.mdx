### add_feedback

`content.add_feedback`: **Review a piece**

Ask for changes on a piece (say what), approve it or reject it; words alone are a note. A Change note becomes a learning in the game's kit and asks for a revised version (a make request the maker picks up). Use it when the person reviews through you. Returns the piece, the learning and the make.

| | |
|---|---|
| **MCP** | `summer_call` with `"op": "content.add_feedback"` |
| **CLI** | `summer content add-feedback` |
| **Runs** | On Summer's servers: the hosted MCP, or the npm MCP after `summer login`. Needs your Summer sign-in. |
| **Effect** | Changes your own drafts, files or settings. Nobody else sees it yet. |
| **Asks you first** | No: **Make and build** is on by default in Agent permissions. When it is off, your agent asks you first. |

**Inputs:**

| Input | Type | Required | Description |
|---|---|---|---|
| `teamId` | string | No | From team.list. Default: the person's only shared team, else their personal workspace. Length 1 to 120. |
| `pieceId` | string | Yes | From content.list_pieces. |
| `verdict` | "approve" \| "changes" \| "reject" | No |  |
| `text` | string | No | What to change, or a note. Length 0 to 2000. |
| `expectedRevision` | integer | No | The revision you read. A save made since then answers conflict instead of being overwritten. Range 0 to 9007199254740991. |
| `dryRun` | boolean | No | Check and describe the call without doing it: nothing changes, nothing is spent. |
| `idempotencyKey` | string | No | Retry key. Reuse it only to retry the identical request, so it never happens twice. Length 1 to 128. |

### save_piece

`content.save_piece`: **Save a finished piece for review**

Save a finished piece for a Content game: one render per platform (library videos) with captions, plus why (the reference it copies, why it fits today), the measured checks, the side by side and the learnings it applied. It waits on Today unless status is draft. Returns it with reviewUrl.

| | |
|---|---|
| **MCP** | `summer_call` with `"op": "content.save_piece"` |
| **CLI** | `summer content save-piece` |
| **Runs** | On Summer's servers: the hosted MCP, or the npm MCP after `summer login`. Needs your Summer sign-in. |
| **Effect** | Changes your own drafts, files or settings. Nobody else sees it yet. |
| **Asks you first** | No: **Make and build** is on by default in Agent permissions. When it is off, your agent asks you first. |

**Inputs:**

| Input | Type | Required | Description |
|---|---|---|---|
| `teamId` | string | No | From team.list. Default: the person's only shared team, else their personal workspace. Length 1 to 120. |
| `contentGameId` | string | Yes | The game's Content id, from content.list_games. |
| `status` | "draft" \| "in_review" | No |  |
| `title` | string | Yes | Length 1 to 120. |
| `format` | string | No | Like trend-swap, devlog, reveal, clutch. Length 0 to 60. |
| `variants` | object[] | Yes | One render per platform. Items 1 to 5. |
| `variants[].platform` | "tiktok" \| "instagram" \| "youtube" \| "youtube_long" \| "x" | Yes |  |
| `variants[].itemId` | string | Yes | The render: a video in the library (content.upload_complete). |
| `variants[].coverItemId` | string | No | The cover: a picture in the library. |
| `variants[].caption` | string | No | Length 0 to 2200. |
| `variants[].title` | string | No | YouTube title. Length 0 to 120. |
| `variants[].hashtags` | string[] | No | Items 0 to 30. |
| `variants[].firstComment` | string | No | Length 0 to 500. |
| `variants[].suggestedSound` | string | No | Length 0 to 200. |
| `sourceItemIds` | string[] | No | The library clips it was made from. Items 0 to 40. |
| `referenceId` | string | No | The reference it follows, from content.list_references. Length 0 to 81. |
| `gameplaySeconds` | number | No | Seconds of real game footage in it. Range 0 to 36000. |
| `selfScore` | number | No | Your own critic's score. Range 0 to 10. |
| `notes` | string | No | What it is and what you chose, for the reviewer. Length 0 to 4000. |
| `why` | object | No | Why this piece: shown under the player on Today. |
| `why.referenceId` | string | Yes | The reference it copies beat for beat (content.list_references). Length 1 to 81. |
| `why.fitReason` | string | No | One line on why it fits today, like the change you saw: "You shipped the Arena waiting room today (commit 3f2a1c: Add waiting room)". Length 0 to 300. |

| `why.refStats.likes` | number \| null | No |  |
| `why.refStats.shares` | number \| null | No |  |
| `why.refStats.breakoutRatio` | number \| null | No | Its views over the account's usual. |
| `why.refStats.postedAt` | string \| null | No |  |
| `why.commit` | object | No | The commit it shows. |
| `why.commit.sha` | string | Yes |  |
| `why.commit.title` | string | No | Length 0 to 200. |

| `checks[].pass` | boolean | Yes |  |
| `sideBySideItemId` | string | No | A library video: the reference left, this piece right, synced on the beats. |
| `contactSheetItemId` | string | No | A library picture: a frame every half second. |
| `learningIds` | string[] | No | The kit learnings this piece applied (content.get_kit learnings). Items 0 to 20. |
| `tomorrow` | object | No | What you plan to make next. |
| `tomorrow.formatType` | string | No | Length 0 to 60. |
| `tomorrow.about` | string | Yes | Length 1 to 200. |
| `makeId` | string | No | The make request it came from (content.claim_make). |
| `dryRun` | boolean | No | Check and describe the call without doing it: nothing changes, nothing is spent. |

### upload_begin

`content.upload_begin`: **Start a content library upload**

Start putting a file in a team's Content library: a video up to 2 GB, or a picture, sound or PDF up to 200 MB. Returns a link that takes one PUT of the file with its content type, for an hour. Next: content.upload_complete.

| | |
|---|---|
| **MCP** | `summer_call` with `"op": "content.upload_begin"` |
| **CLI** | `summer content upload-begin` |
| **Runs** | On Summer's servers: the hosted MCP, or the npm MCP after `summer login`. Needs your Summer sign-in. |
| **Effect** | Changes your own drafts, files or settings. Nobody else sees it yet. |
| **Asks you first** | No: **Make and build** is on by default in Agent permissions. When it is off, your agent asks you first. |

**Inputs:**

| Input | Type | Required | Description |
|---|---|---|---|
| `teamId` | string | No | From team.list. Default: the person's only shared team, else their personal workspace. Length 1 to 120. |
| `fileName` | string | Yes | Length 1 to 200. |
| `contentType` | string | Yes | Like video/mp4 or image/png. Length 3 to 100. |
| `size` | integer | Yes | Bytes. Range … to 9007199254740991. |
| `dryRun` | boolean | No | Check and describe the call without doing it: nothing changes, nothing is spent. |
| `idempotencyKey` | string | No | Retry key. Reuse it only to retry the identical request, so it never happens twice. Length 1 to 128. |

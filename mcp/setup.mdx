One command connects your agent to Summer. It works for 31 agents, and on Windows and Mac. Using a chat app such as Claude or ChatGPT? Skip to [the hosted server](#hosted-server-for-chat-apps).

## Set up your agent

**You need:** [Node.js](https://nodejs.org) 22 or newer. The [Summer app](/essentials/installation) already brings its own copy and connects the agents it finds, so you can skip this page if you installed it.

<CodeGroup>

```bash Claude Code
npx -y summer-engine@latest setup claude-code --yes
```

```bash Codex
npx -y summer-engine@latest setup codex --yes
```

```bash Cursor
npx -y summer-engine@latest setup cursor --yes
```

```bash VS Code
npx -y summer-engine@latest setup vscode-copilot --yes
```

```powershell Windows PowerShell
npx.cmd -y summer-engine@latest setup claude-code --yes
```

</CodeGroup>

For any other agent, use its id from [Every agent](#every-agent). The command:

1. **Writes the Summer MCP server** (`summer-engine`) into your agent's own config file. Servers already in the file stay.
2. **Installs the Summer skills** where your agent reads them. See [Skills](/mcp/skills).
3. **Adds the [Summer Games MCP](/mcp/summer-games)** (`summer-games`) for friends, parties and messages, and prints its one sign-in step. `--no-games` skips it.
4. **Runs `summer doctor`**, which checks Node.js, Summer Engine, your sign-in and your agent's config.

In Claude Code you can install the Summer plugin instead: `/plugin install summer --marketplace summerengine/summer`, then `/summer:start`. Use the plugin or `summer setup`, not both.

## Check that it works

Restart your agent so it loads the new server. Then ask it:

```text
List the Summer tools you have.
```

**If everything worked:** your agent lists tools such as `summer_play`, `summer_screenshot` and `summer_search`. You can also look in your agent's MCP list: `/mcp` in Claude Code and Codex, **Settings > MCP** in Cursor. It shows `summer-engine` as connected.

Then try a real task: "Make a small 3D game in Summer, play it and show me a screenshot." Your agent installs Summer Engine if it is missing (it asks you first), creates the project and opens it.

## Sign in

Building and playing games needs no sign-in. For assets, publishing and the rest of the cloud work, sign in once:

```bash
npx -y summer-engine@latest login
```

Your browser opens the Summer sign-in page. Sign in and choose **Allow**. The local server then also runs every cloud operation, so your agent needs only one Summer server. If your agent calls a cloud tool before you sign in, it gets a sign-in link and continues once you sign in.

## Hosted server for chat apps

Chat apps without a terminal connect to Summer's hosted server. It does cloud work only: assets, plans, the store page, publishing, prices and analytics. It has no engine tools. You sign in with your Summer account the first time your agent connects.

<CodeGroup>

```bash Claude Code
claude mcp add --transport http summer-cloud https://mcp.summerengine.com/mcp
# then run /mcp and sign in
```

```bash Codex
codex mcp add summer-cloud --url https://mcp.summerengine.com/mcp
codex mcp login summer-cloud
```

```json Cursor (~/.cursor/mcp.json)
{
  "mcpServers": {
    "summer-cloud": { "url": "https://mcp.summerengine.com/mcp" }
  }
}
```

```bash VS Code
code --add-mcp '{"name":"summer-cloud","type":"http","url":"https://mcp.summerengine.com/mcp"}'
```

</CodeGroup>

In Claude and Claude Desktop, open **Settings > Connectors > Add custom connector** and paste `https://mcp.summerengine.com/mcp`. For ChatGPT, see [Summer in ChatGPT and Claude](/mcp/chatgpt-and-claude).

<Note>
`https://docs.summerengine.com/mcp` only searches these docs. To connect Summer, use `https://mcp.summerengine.com/mcp`.
</Note>

## Setup options

| Option | What it does |
|---|---|
| `--scope project` | Writes project files that travel with the game, in place of your user config |
| `--cli` | Installs the skills and no MCP server. Your agent runs `summer` commands in its shell |
| `--profile engine` | Lists the engine tools only, for agents with a tool limit. VS Code Copilot gets it by default |
| `--assets-only` | Sets up the asset tools and skills only, with no engine |
| `--print` / `--dry-run` | Shows the config or the plan without writing anything |
| `--force` | Refreshes the skills after you update Summer |

Every option: [summer setup](/mcp/cli-reference#summer-setup).

## Manual configuration

If you would rather edit files yourself, or your agent is not listed, these are the shapes in use. `summer setup <agent> --print` prints the exact one for any agent.

<CodeGroup>

```json mcpServers (Cursor, Claude Code, Claude Desktop, Kiro, Qwen, Kimi, Warp, ...)
{
  "mcpServers": {
    "summer-engine": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "summer-engine@latest", "mcp"]
    }
  }
}
```

```json servers (VS Code, Visual Studio, Copilot in JetBrains)
{
  "servers": {
    "summer-engine": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "summer-engine@latest", "mcp"]
    }
  }
}
```

```json mcp (OpenCode, Kilo Code)
{
  "mcp": {
    "summer-engine": {
      "type": "local",
      "command": ["npx", "-y", "summer-engine@latest", "mcp"],
      "enabled": true
    }
  }
}
```

```json context_servers (Zed settings.json)
{
  "context_servers": {
    "summer-engine": {
      "command": "npx",
      "args": ["-y", "summer-engine@latest", "mcp"],
      "env": {}
    }
  }
}
```

```toml TOML (Codex ~/.codex/config.toml, Grok Build)
[mcp_servers.summer-engine]
command = "npx"
args = ["-y", "summer-engine@latest", "mcp"]
```

```yaml YAML (Goose ~/.config/goose/config.yaml)
extensions:
  summer-engine:
    type: stdio
    name: summer-engine
    cmd: npx
    args: ["-y", "summer-engine@latest", "mcp"]
    enabled: true
    timeout: 300
```

</CodeGroup>

<Tip>
**Windows.** `npx` is a shell shim, and hosts that spawn it directly fail with ENOENT. `summer setup` writes `"command": "cmd.exe", "args": ["/c", "npx", "-y", "summer-engine@latest", "mcp"]` on Windows; do the same by hand.
</Tip>

<Tip>
**No global install required.** `npx -y summer-engine@latest mcp` runs the current release on demand. For faster startup install it (`brew install summerengine/tap/summer` or `npm install -g summer-engine`) and use `"command": "summer", "args": ["mcp"]`.
</Tip>

## Troubleshooting

<AccordionGroup>
  <Accordion title="My agent does not list any Summer tools">
    Restart the agent: most agents load a new MCP server only at start. Then run `npx -y summer-engine@latest doctor`, which shows whether your agent's config points at Summer.
  </Accordion>
  <Accordion title="A tool answers engine_not_running">
    Summer Engine is not open. Ask your agent to open your project, or run `npx -y summer-engine@latest dev` in the game's folder. Cloud tools work without the engine.
  </Accordion>
  <Accordion title="Windows: running scripts is disabled on this system">
    Type `npx.cmd` in place of `npx` in PowerShell. Don't change the execution policy.
  </Accordion>
  <Accordion title="summer doctor says Node.js is too old">
    Summer needs Node.js 22 or newer. Install the current LTS from [nodejs.org](https://nodejs.org) (on Windows: `winget install -e --id OpenJS.NodeJS.LTS`), then restart your agent.
  </Accordion>
</AccordionGroup>

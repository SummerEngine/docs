The `summer cloud` command group (`init`, `status`, `push`, `pull`, `restore`,
`checkpoints`, `conflicts`) and the seven `summer_cloud_*` MCP tools were a
research preview in summer-engine 2.x. They were removed in summer-engine 3.0.
The current CLI has no `summer cloud` command, and running it fails.

## What to use instead

| You want to | Use |
|---|---|
| Move your project to another machine, or work on it with others | Git. See [Git and GitHub](/guides/github-from-changes-dock). Use Git LFS for big assets. |
| Get your game to players | [Create and publish your game](/publishing/summer-games): export, upload a build, and publish to Summer Games. |
| See every command the CLI has | [CLI reference](/mcp/cli-reference) |
| See every tool your agent can call | [MCP tools reference](/mcp/tools-reference) |

## Old projects

A project bound with 2.x may still have a `summer-cloud.json` file at its root
and a `.summer/local/cloud/` folder. Nothing reads them any more, so you can
delete both. A `~/.summer/cloud-token` file from a 2.x sign-in is never read;
`summer logout` removes it.

Summer Engine, the game engine built for AI, sends parts of your project to AI
models when you use the agent. This page says what goes where, who processes
it, and what you control.

The full, current list of providers is the
[Service Providers (Subprocessors) list](https://www.summerengine.com/legal/subprocessors).
If this page and that list disagree, the list is right.

## What leaves your computer

Your project lives on your computer. These parts of it leave your computer:

| What | When | Where it goes |
|---|---|---|
| Your prompts, and the code, scenes and files the agent reads for a turn | When you chat with the agent or call an AI tool | Summer's API, then the AI model provider that runs the model you use |
| A search index of your project (source chunks, file paths, file metadata and embeddings) | When Project Intelligence indexes your project | turbopuffer |
| Generated and uploaded assets | When you create or upload assets in Summer Studio | Summer's file storage |
| Builds you publish | When you or your agent uploads a build to Summer Games | Summer Games hosting |
| Usage events, such as "project opened" | While you use Summer Studio and the desktop Editor | PostHog (EU) |
| Error and crash reports | When the website or the desktop Editor fails | Sentry (EU) |

Summer has no project sync for desktop projects. Use Git to back your project
up; see [Connect your project to GitHub](/guides/github-from-changes-dock).

## AI model providers

Summer routes most chat requests through the Vercel AI Gateway to the provider that
runs the model you pick, or the model Auto picks for you. Providers include
OpenAI, Anthropic, Google and others. Image, video, 3D and audio generation run
through fal and ElevenLabs. The subprocessors list names every provider.

See [Privacy Mode](/security/privacy-mode) and the
[Privacy Policy](https://www.summerengine.com/privacy) for how Summer and its
model providers handle prompts and code.

## Your control

- **Delete your account.** In Settings, type **delete my account** and select
  **Delete Account**. You can also email
  [support@summerengine.com](mailto:support@summerengine.com).
- **Privacy requests** (access, correction, export, deletion): email
  [support@summerengine.com](mailto:support@summerengine.com) with the subject
  "Privacy request".
- **Keep secrets out of prompts.** Do not paste API keys or passwords into chat.
  Keep them out of files the agent reads, for example in environment variables
  or files your `.gitignore` excludes.
- **Approve what the agent does.** The chat's permission mode decides what runs
  without asking. **Manual** asks before edits, paid tools and commands that change
  anything.

## Report a security issue

Email [support@summerengine.com](mailto:support@summerengine.com) with the
subject "Security report". Do not post security issues in Discord or anywhere
public.

The [Vulnerability Disclosure Policy](https://www.summerengine.com/legal/security)
covers what is in scope, the safe harbor for good-faith research, and
coordinated disclosure. Summer acknowledges reports within 3 business days.

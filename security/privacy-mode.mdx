## Current status

Privacy Mode is not available in Summer Engine today. There is no Privacy Mode
setting in your account, on any plan, and Summer does not turn on zero data
retention with its AI model providers.

If an older page or answer says Privacy Mode is "included on all paid plans" or
can be turned on in account settings, that is out of date.

## What happens to your prompts and code

When you chat with Summer, the prompt you write and any code or project context
attached to it go to the provider that runs the model you picked, or the model
[Auto](/auto-mode/auto) picked for you. The provider processes it to generate the
reply. Each provider's own retention terms apply.

The [Privacy Policy](https://www.summerengine.com/privacy#prompts-and-code) is the
legal text for how Summer stores and uses prompts and code. The
[subprocessors list](https://www.summerengine.com/legal/subprocessors) names every
provider that can receive this data.

For what leaves your computer and where it goes, see the
[Security Overview](/security/overview).

## If you work on sensitive code

- Keep secrets out of your project files and out of chat. API keys, passwords and
  tokens do not belong in prompts.
- Use Git, so you can review every change before you keep it. See
  [Connect your project to GitHub](/guides/github-from-changes-dock).
- Content you send as feedback or in a bug report may be read by the Summer team
  to fix the problem.

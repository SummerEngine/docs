## What is Summer Engine?

Summer is **the game engine built for AI**. Any agent builds, tests and publishes a full multiplayer game. Not an engine with a chatbot bolted on: a full professional engine where AI understands your whole project and builds scenes, code and assets for you.

Connect Claude Code, Codex, Cursor, Claude, ChatGPT or any other agent: add one URL and sign in once. For engine work, one command adds the local server. Or use
**Summer Agent** inside the app. Your agent builds a full **Summer game**: scenes, code
and assets. The **Summer SDK** adds what online games need, and Summer runs it for you: servers,
matchmaking, parties, saves, leaderboards, chat and a store. When the game is ready, your agent
publishes it on [Summer Games](https://summer.games).

**A full engine for full games.** 2D and 3D, physics, animation, native C++ and C#, and export to desktop, mobile and the web. You describe what you want; Summer Engine writes the code, creates the assets and changes your game directly.

## How Summer Engine Differs from Other Approaches

**Unified experience.** No switching between tools. The AI understands your project context because it indexes your codebase, scenes, and assets. When you ask "add a health bar to my player," it knows which player script and scene to modify.

**Accountable operations.** Scene changes go through engine operations that name an exact target and join the editor's undo history, so Ctrl+Z reverts them. File writes return exact receipts and refuse stale overwrites; use the Changes panel or Git to roll them back.

**Project intelligence.** Summer Engine automatically indexes your project when you open it: scripts, scenes, assets, and their relationships. The AI uses this to give context-aware help, not generic advice.

**Specialist agents.** The main agent hands work to a fixed team: a researcher, a builder, an asset maker, a verifier and an advisor. They run in parallel, each with its own focused context. See [How do specialist agents work?](/knowledge-base/specialist-agents).

## Who Is Summer Engine For?

Summer Engine is for everyone who wants to make games. Beginners can build complete games by describing them in plain English. Professionals get a production-ready tool that accelerates workflow. We built *Don't Pray*, our own game on Steam, in 2.5 months with Summer Engine. You get full access to the underlying engine and complete control over your architecture.

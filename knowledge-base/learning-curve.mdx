**Minutes to start, as deep as you want to go.** You do not need to learn the engine before you make a game. You describe what you want, and your agent builds it in Summer Engine.

- **Day one**: install Summer Engine, describe a game in plain words and press Play. Summer Agent, or Claude Code, Codex or Cursor through MCP, writes the code and builds the scenes.
- **Learn as you build**: ask the agent to explain what it did and why. It shows the nodes, scripts and settings it changed, so you learn on your own project.
- **Go deeper when you want**: the full engine is there. Edit scenes and GDScript by hand, or use C++ and C# for native work.

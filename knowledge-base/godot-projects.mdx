**Yes. Open a committed copy and check the first import.** Summer Engine reads the standard project, scene, script and resource formats. Compatibility ranges are not fully measured yet, so check the result before you build on it.

- **Commit first.** The first open can reimport assets and update project settings. Review those changes in Git.
- **What carries over**: GDScript, `.tscn` scenes, `.tres` resources and your assets.
- **What to test**: native extensions, editor plugins and addons pinned to another engine version.
- **Then build on it with AI**: your agent reads the project and keeps building. You can also add multiplayer with the Summer SDK.

The generated [compatibility reference](/reference/compatibility) is the source of truth for the current upstream base and measured claims. For the full checklist, see [Is Summer Engine compatible with my existing project?](/knowledge-base/godot-compatibility).

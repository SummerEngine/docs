**Summer Engine is a full game engine built for AI.** Many AI game tools are a chat plugin added to an existing editor, or a website that turns a prompt into a small browser game. Summer is the engine itself, and any agent can work in it.

- **Agents work inside the engine.** Through Summer's operations an agent adds nodes, sets properties, runs the game, reads the errors and takes screenshots. It does not just suggest code for you to paste.
- **Any agent.** Use Summer Agent in the app, or connect Claude Code, Codex, Cursor, Claude, ChatGPT and other agents through MCP.
- **Full games, not demos.** 2D and 3D, physics, animation, native C++ and C#. Summer runs servers, matchmaking and saves for online games.
- **You own the result.** Your project is plain files you keep in Git. Export standalone builds and publish on Summer Games, Steam or your own site.

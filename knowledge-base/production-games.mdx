**Yes.** We built *Don't Pray* with Summer Engine in 2.5 months. That is a project that would have taken us one to two years before Summer. It is a live game with real players, not a demo.

- **What it is**: an online PvP magic shooter. Teams fight in an arena and pray to statues for powers.
- **Where it is**: on [Steam](https://store.steampowered.com/app/4176260/Dont_Pray/) as a free-to-play Early Access game for Windows, since February 2026.
- **What it uses**: 3D combat, online multiplayer, in-game purchases and Steam integration, all built in Summer Engine.

Summer Engine is a full game engine, so the same path is open to you: build with AI, export a standalone build and ship it on Steam, Summer Games or your own site.

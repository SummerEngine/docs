Your agent publishes through Summer operations: one name such as `store.publish`, one input, one answer. This page says which operation does each publishing job. Every input, answer and example is in the generated [Operations reference](/mcp/operations).

## How your agent calls them

- **Hosted MCP** (`https://mcp.summerengine.com/mcp`): the common jobs are their own tools, such as `summer_games_list`, `summer_store_get_listing`, `summer_store_update_listing`, `summer_store_status` and `summer_store_publish`. Any other operation runs through `summer_call`: `{"op": "store.set_art", "input": {...}}`. `summer_search` finds an operation from the job in plain words.
- **npm MCP** on your computer: the same operations after `summer login`, plus the local ones that touch your disk (export and upload from a file).
- **3.x tool names** such as `summer_store_submit` still work through `summer_call` for all of 4.x. See [3.x tool names](/mcp/operations/legacy-names).

What runs at once and what asks you first: [Agent permissions](/mcp/permissions). Setup: [Connect your agent](/publishing/connect-your-agent).

## Find the game

| Job | Operation |
|---|---|
| List your Summer projects | [`projects.list`](/mcp/operations/projects#list) (`summer_projects_list`) |
| Read one project and its plan | [`projects.get`](/mcp/operations/projects#get) |
| List your games on Summer Games | [`games.list`](/mcp/operations/games#list) (`summer_games_list`) |
| Create a game with its first store page draft | [`games.create`](/mcp/operations/games#create) |

A Summer project and its game on Summer Games are separate records.

## Store page

| Job | Operation |
|---|---|
| Read the store page and its publish checklist | [`store.get_listing`](/mcp/operations/store#get_listing) (`summer_store_get_listing`) |
| Edit the draft: title, targets, text, tags, age rating | [`store.update_listing`](/mcp/operations/store#update_listing) (`summer_store_update_listing`) |
| Put pictures into an art slot | [`store.set_art`](/mcp/operations/store#set_art) |
| Set the trailer | [`store.set_trailer`](/mcp/operations/store#set_trailer) |
| Remove the trailer (asks first: Delete for good) | [`store.remove_trailer`](/mcp/operations/store#remove_trailer) |
| Set the sound loop of the page | [`store.set_sound`](/mcp/operations/store#set_sound) |
| Make a private preview link | [`store.preview_link`](/mcp/operations/store#preview_link) |

Text rules: [Store page text](/publishing/store-text). Slot sizes: [Store art](/publishing/store-art).

## Art

| Job | Operation |
|---|---|
| Find art you already have | [`assets.search`](/mcp/operations/assets#search) with `scope: "mine"` (`summer_assets_search`) |
| Make a picture, then wait for it | [`assets.generate_image`](/mcp/operations/assets#generate_image) (`summer_assets_generate_image`), then [`jobs.wait`](/mcp/operations/jobs#wait) |
| Upload a picture from your disk | [`assets.upload_begin`](/mcp/operations/assets#upload_begin), then [`assets.upload_complete`](/mcp/operations/assets#upload_complete) |
| Cut out an icon subject | [`assets.remove_background`](/mcp/operations/assets#remove_background) |
| Read the game's look | [`plans.get`](/mcp/operations/plans#get) and [`plans.directions`](/mcp/operations/plans#directions) (saved directions) |
| Real gameplay screenshots | [`summer_capture_gameplay`](/mcp/tools/build#summer_capture_gameplay) and `summer_screenshot` (npm MCP) |

See [Make store art with your agent](/publishing/generate-store-art).

## Build and upload

| Job | Operation |
|---|---|
| Export the game (npm MCP) | [`summer_export_game`](/mcp/tools/publish#summer_export_game), with [`summer_export_templates`](/mcp/tools/publish#summer_export_templates) for web and downloads |
| Upload an export from your disk (npm MCP) | `store.upload_file`: the tool [`summer_publish_build`](/mcp/tools/publish#summer_publish_build) |
| Upload without the npm MCP | [`store.upload_begin`](/mcp/operations/store#upload_begin), [`store.upload_sign_parts`](/mcp/operations/store#upload_sign_parts), [`store.upload_complete`](/mcp/operations/store#upload_complete) |
| See every upload, the review and what players get | [`store.status`](/mcp/operations/store#status) (`summer_store_status`) |
| Remove an unused build or file (asks first) | [`store.remove_build`](/mcp/operations/store#remove_build), [`store.remove_file`](/mcp/operations/store#remove_file) |

Step by step: [Upload and publish](/publishing/upload-and-submit).

## Publish and release

| Job | Operation |
|---|---|
| Publish the draft with a build and a price (needs an `idempotencyKey`) | [`store.publish`](/mcp/operations/store#publish) (`summer_store_publish`) |
| Wait for a job or an approval | [`jobs.wait`](/mcp/operations/jobs#wait) (`summer_jobs_wait`) |
| Withdraw a publish request that still waits | [`store.cancel_publish`](/mcp/operations/store#cancel_publish) |
| Release the build that passed review (needs an `idempotencyKey`) | [`store.release`](/mcp/operations/store#release) |
| Write the release notes players read | [`store.update_release_notes`](/mcp/operations/store#update_release_notes) |

If an answer is `needs_approval`, give the owner `approval.url` and wait with `summer_jobs_wait`. See [Approvals](/publishing/owner-approval).

## After launch

| Job | Operations |
|---|---|
| Numbers for all your games | [`analytics.overview`](/mcp/operations/analytics#overview) |
| One game's numbers | [`analytics.summary`](/mcp/operations/analytics#summary) (`summer_analytics_summary`) |
| Prices and sales | [Pricing](/mcp/operations/pricing): `pricing.get` (`summer_pricing_get`), `pricing.set_base`, `pricing.set_country`, `pricing.clear_country`, `pricing.schedule_discount`, `pricing.clear_discount` |
| Store page A/B tests | [A/B tests](/mcp/operations/experiments): `experiments.list`, `experiments.create`, `experiments.start`, `experiments.stop`, `experiments.results` |
| People on a game | [Games](/mcp/operations/games): `games.members`, `games.set_member_role`, `games.invite_member` (asks first: Contact people) |
| Promotions, ads and featured places (asks first: Contact people) | [Marketing](/mcp/operations/marketing): `marketing.apply`, `marketing.applications` |
| Your teams | [Teams](/mcp/operations/team): `team.list`, `team.create`, `team.rename`, `team.invite` |

More: [Use the agent for Grow](/grow/use-the-agent).

## Before sign-in

Before `summer login`, the npm MCP answers cloud operations with the error `not_signed_in` and one next step: run `npx -y summer-engine login`. The hosted MCP asks you to sign in when you connect it.

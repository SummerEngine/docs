## Make a web game with Summer Engine

Summer Engine is the game engine built for AI. Build your game with Summer Agent or your own coding agent, export a web build, and players play it in the browser: on [summer.games](https://summer.games), itch.io or your own site.

## Step 1: Build your game

<Steps>
  <Step title="Download Summer Engine">
    Download it from [summerengine.com/download](https://summerengine.com/download) for Mac (Apple silicon) or Windows. See [Install Summer Engine](/essentials/installation).
  </Step>
  <Step title="Create a project">
    Start a new project and give it a name.
  </Step>
  <Step title="Describe your web game">
    For example: "Create a browser game where you catch falling objects" or "Make a clicker game with a counter".
  </Step>
</Steps>

## Step 2: Export a web build

Ask your agent to run `summer_export_game` with `targets: ["web"]`. It builds on Summer's WebGPU web template, with threads off, for projects on the **Forward+** or **Mobile** renderer. You get a `.zip` with `index.html` at its root. It does not export **Compatibility** projects: switch the renderer to Forward+ or Mobile first.

If the web template is missing, install it with `summer_export_templates` (`"action": "install", "platforms": ["web"]`). Do not use the editor's own template download: it fetches stock templates, not Summer's. See [Export your game](/publishing/export).

## Step 3: Publish

- **Summer Games**: in Summer Studio, upload the `.zip` in the **Web** box. Players get a Play button on your game's page. Up to 500 MB, 2,000 files and 200 MB per file. See [Publish your game](/grow/publish#web-exports).
- **itch.io or your own site**: upload the contents of the `.zip` to any static host.

## Prompts for web games

- "Add touch controls for mobile browsers"
- "Scale the UI for different screen sizes"
- "Save progress between visits"
- "Add a loading screen with a progress bar"

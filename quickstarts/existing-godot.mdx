## Use Summer Engine with Your Existing Project

Summer Engine is the game engine built for AI. It opens projects in the same formats as its
upstream base: GDScript, text scenes and resources. Summer does not state a minimum project
version yet, so commit your project first, open it in Summer Engine, and treat the first
import as a test.

## Step 1: Download and Install Summer Engine

<Steps>
  <Step title="Download Summer Engine">
    Download it from [summerengine.com/download](https://summerengine.com/download) for Mac (Apple silicon) or Windows.
  </Step>
  <Step title="Create your account">
    Open Summer Engine, click "Sign in", and create an account with Google, GitHub or email.
  </Step>
</Steps>

## Step 2: Open Your Project

<Steps>
  <Step title="Open your project">
    In the Project Manager, choose **Import**, browse to your project folder and select its `project.godot` file.
  </Step>
  <Step title="Wait for indexing">
    Summer Engine indexes your project, so Summer Agent can search your scenes, scripts and assets. Larger projects take longer.
  </Step>
  <Step title="Start chatting">
    Describe what you want to change. Try: "Add a health bar to my player" or "Optimize this scene for mobile"
  </Step>
</Steps>

## What to expect

- **GDScript, text scenes, resources and assets** open as they are.
- **Plugins and libraries** need a test when they are native, editor plugins, or pinned
  to one engine version.
- **Imports and exports**: check them on the Summer Engine version you ship with.
- **Teams**: everyone uses the same Summer Engine version, and you review the changes
  the first open makes.

## Zero Lock-in

Your project files stay in open, documented formats. Commit before the first open so you can
review the import and settings changes. See
[Compatibility & upstream](/reference/compatibility) for the current upstream base and what is measured.

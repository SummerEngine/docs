**Your game can be multiplayer from day one.** Summer runs a server for every
match and brings players together through matchmaking. It also keeps their
progress, ranks them on leaderboards and runs your store. You don't rent or
manage any machines. Describe the game you want, and your coding agent builds
it with Summer's skills.

## Start with one prompt

Open your Summer game and copy this into your coding agent. It sets up your
server and runs a test with several players on your own computer.

<Prompt description="**Make my game multiplayer.** A client and a server, joining a match, and a first test with several players.">
Make my Summer game multiplayer. Use the Summer `multiplayer` skill first to
explain how it fits my game, then `multiplayer-project` to set it up; if you
don't have them installed, find them in the Summer library.

- Read my project and tell me which parts become the server and which stay on
  each player's device before you change anything.
- Set up the client and server scenes, the World and a queue, and joining.
- Start a Local Play test with two players and tell me what you saw.
</Prompt>

Then follow [Make your game multiplayer](/build/multiplayer) to see how it all
fits together.

## Ready to ship?

When it plays well, [publish your game](/build/publish): export one file, make
your store page in Summer Studio, and go live on summer.games. Summer runs your
servers from then on.

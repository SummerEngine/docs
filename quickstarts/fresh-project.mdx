## Make a Summer game

Summer Engine is the game engine built for AI. Start with an empty project and describe what you want to play. Your agent
builds it and you play it in the editor. When you want players online, the next guide adds the
**Summer SDK** for multiplayer, and then you publish.

## Step 1: Download Summer Engine

Download Summer Engine for free.

<AccordionGroup>
  <Accordion icon="download" title="Get Summer Engine for free">
    **For Mac users:**
    - Visit [summerengine.com/download](https://summerengine.com/download) and click **Download for macOS** (Apple silicon Macs)
    - Drag Summer Engine to your Applications folder
    - Double-click to open. macOS may ask for permission; that is normal.

    **For Windows users:**
    - Visit [summerengine.com/download](https://summerengine.com/download) and click **Download for Windows**
    - Run the installer. If Windows asks for permission, click **Yes**.

    <Tip>Summer Engine is free to download and try. No credit card required.</Tip>

    Using your own coding agent? `npx -y summer-engine@latest install` installs Summer Engine from the command line. See [Install Summer Engine](/essentials/installation).
  </Accordion>
  <Accordion icon="user" title="Create your account">
    1. **Open Summer Engine.**
    2. **Click "Sign in".** This opens your web browser.
    3. **Create an account** with Google, GitHub or email.
    4. **Go back to Summer Engine.** The app signs you in.

    <Tip>You sign in in your browser, so Summer Engine never sees your password.</Tip>
  </Accordion>
</AccordionGroup>

## Step 2: Build Your First Summer Game

<AccordionGroup>
  <Accordion icon="plus" title="Start a new Summer game">
    1. **Create a new project** in the Project Manager and give it a name.
    2. **Choose a location** on your computer.
    3. **Click "Create".** Summer Engine opens with the chat panel.
    4. **Wait a few seconds** while Summer Agent reads your new project.

    <Tip>You talk to Summer Agent in the chat panel.</Tip>
  </Accordion>
  <Accordion icon="message-square" title="Have your first conversation">
    Try typing these:

    **"Create a player character that I can move around"**
    - Summer Agent creates a character
    - Adds movement controls (arrow keys or WASD)
    - Press the play button to test it

    **"Add some platforms to jump on"**
    - Summer Agent creates platforms in your game world
    - Sets up physics so your character can land on them

    **"Make the camera follow my player"**
    - Summer Agent adds a smooth camera that follows your character

    <Tip>You do not need to be precise. Describe what you want in plain words.</Tip>
  </Accordion>
</AccordionGroup>

## Understanding the Interface

Summer Engine is a full game editor with Summer Agent built in.

<AccordionGroup>
  <Accordion icon="layout" title="Chat panel (right side)">
    - **Multiple chat tabs**: a conversation per feature
    - **Change review**: see what Summer Agent wants to change before it applies it
    - **Sources**: the files Summer Agent reads from your project
  </Accordion>
  <Accordion icon="git-branch" title="Built-in Git integration">
    - **Changes panel**: your real repository, with changed, staged and conflicted files grouped
    - **Stage, commit, push**: per file, from the panel or by asking Summer Agent
    - **Summer Agent can run git for you**: status, diff, stage, commit, branch, fetch, pull, push. It writes the commit message when it commits
  </Accordion>
</AccordionGroup>

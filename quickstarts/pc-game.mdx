## Make a Windows PC game with Summer Engine

Summer Engine is the game engine built for AI. Build your game with Summer Agent or your own coding agent, then export a Windows `.exe`.

## Step 1: Build your game

<Steps>
  <Step title="Download Summer Engine">
    Download it from [summerengine.com/download](https://summerengine.com/download) for Windows or Mac (Apple silicon). See [Install Summer Engine](/essentials/installation).
  </Step>
  <Step title="Create a project">
    Start a new project and describe what you want: "Create a 2D platformer" or "Build a top-down shooter".
  </Step>
  <Step title="Iterate with AI">
    Refine it in conversation: "Add a health system", "Make the enemies smarter", "Add a pause menu".
  </Step>
</Steps>

## Step 2: Turn on PC textures

In **Project → Project Settings → Rendering → Textures → VRAM Compression**, turn on **Import S3TC BPTC** and wait for the reimport. You do this once per project.

## Step 3: Export for Windows

<Tabs>
  <Tab title="With your agent">
    Ask your agent to run `summer_export_game` with `targets: ["windows"]` and `format: "download"`. You get `<name>-windows-x64.zip`: an `.exe` with the game inside. See [Export your game](/publishing/export).
  </Tab>
  <Tab title="In the editor">
    Open **Project → Export → Add → Windows Desktop**, use 64-bit (x86_64), turn on **Embed PCK** for a single `.exe`, and click **Export Project**.
  </Tab>
</Tabs>

The Windows app of Summer Engine comes with the Windows export templates. On a Mac, get them with `summer_export_templates` (`"action": "install", "platforms": ["windows"]`).

## Step 4: Publish

- **Summer Games**: zip the exported folder and upload it in the **Windows** box in Summer Studio. See [Publish your game](/grow/publish).
- **Steam or itch.io**: see [Windows export](/publishing/windows-export) for code signing and store setup.

Usage is billed from your Summer account; spend is visible in Studio. There is no separate account and no key to manage. Players never pay.

## Caps

Summer enforces hard caps before any call reaches a provider. They are on by default.

| Cap | Window | Who sets it |
| --- | --- | --- |
| Per player per day | Calendar day (UTC) | The game's owner |
| Per game per day | Calendar day (UTC) | The game's owner |
| Per game per month | Calendar month (UTC) | The game's owner |
| Per account per month | Calendar month (UTC), across all your games | You |
| Per character per player per day, per character per day | Calendar day (UTC) | The character file (`limits`) |

When a cap is reached, calls in that scope fail with `limit_reached`, with the `scope` and `resets_at`. Players never see the amount. The game uses its fallback until the reset.

## Read and change caps

```bash
summer router limits get
summer router limits set --player-day 0.50 --game-day 20 --game-month 300
summer router limits set --enabled off
```

Amounts are US dollars of usage. `limits get` shows each cap, how much of it is used (a percentage) and when it resets.

Only the game's owner changes caps, the on/off switch and the default models. When an agent runs `limits set`, Summer answers `owner_action_required` with one Studio link; the owner opens it and saves. The owner can also change everything in Studio: the **Router** tab of the game's store page (`https://www.summerengine.com/studio/store/<gameId>?view=all&tab=router`).

## Turn it off

`summer router limits set --enabled off`, or the switch in Studio. The next call gets `router_disabled` and the game uses its fallback.

## Usage

- Studio shows calls and units per day and per kind, and each cap's use.
- `summer router logs --since 1d` lists recent calls for an agent.
- Every call result in GDScript carries `usage`: tokens, characters, seconds or images. Never a price.

## Credits

When your Summer account needs credits, calls fail with `credits_required` and a link to Studio. Add credits there; the next call works.

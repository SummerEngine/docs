<Warning>
**Preview.** Runs when the Summer Router platform and the engine release with `Summer.client.router` ship.
</Warning>

```gdscript
var r := await Summer.client.router.reply("guard", "Is the gate open?")
if r.ok:
	$HUD/Subtitle.text = r.text
else:
	_use_fallback()   # r.error, r.fix
```

For a conversation with tools, use a session (`Summer.client.router.talk("guard", {"mode": "text"})`) or the `SummerRouterCharacter` node: they call your tool handlers and send the results back for you. See [GDScript](/router/gdscript).

## Input

| Field | Rule |
| --- | --- |
| character | A pushed character id |
| text | 1 to 4,000 characters |
| options.conversation_id | Continue a conversation (Summer keeps the history; the game never sends it) |
| options.variables | Only when the character lists `variables` in `overridable` |
| options.context | Up to 4,000 characters: what just happened in the game |

## Result

| Field | Meaning |
| --- | --- |
| `text` | The reply |
| `tool_calls` | `[{call_id, name, args, runs_on}]` the character wants the game to run |
| `exchange_id` | The id of this turn, for `speak` and reports |
| `usage` | `input_tokens`, `output_tokens` |

Errors: [Errors](/router/errors). Common: `character_not_found`, `limit_reached`, `router_disabled`, `moderated`.

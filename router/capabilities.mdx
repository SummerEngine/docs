Each capability is one call from your game. Summer picks the model you set for the game, runs it, and meters the call from your Summer credits.

| Capability | In your game | Metered | Status |
|---|---|---|---|
| [Character reply](/router/character-reply) | `Summer.client.router.reply(character: String, text: String, options: Dictionary = {})` | per token in and out | Available |
| [Character voice session](/router/character-voice) | `Summer.client.router.talk(character: String, options: Dictionary = {"mode": "voice"})` | per second of audio | Coming soon |
| [Speech](/router/speech) | `Summer.client.router.speak(text: String, options: Dictionary = {"character": ""})` | per character spoken | Available |
| [Transcribe](/router/transcribe) | `Summer.client.router.transcribe(clip: AudioStream, options: Dictionary = {})` | per second of audio | Coming soon |
| [Image](/router/image) | `Summer.client.router.generate("image", {"prompt": prompt, "size": "1024x1024"})` | per image | Available |

## Models

You choose the default text model and image model for each game, and a model per character, on the game's Summer Router tab in Studio. Your agent reads the list with the `router.models` operation. Usage in Studio shows calls and units by capability, and how much of each cap is used.

## Input limits

The SDK builds the request from the call's arguments and options. Summer checks these limits:

| Field | Type | Limits |
|---|---|---|
| `audio` (required) | string | 4 to 1398104 characters |
| `mime_type` (required) | `audio/wav`, `audio/ogg`, `audio/mpeg`, `audio/webm`, `audio/mp4` | One of these |
| `language` | string | Any |

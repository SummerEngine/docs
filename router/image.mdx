<Warning>
**Preview.** Runs when the Summer Router platform and the engine release with `Summer.client.router` ship.
</Warning>

```gdscript
var img := await Summer.client.router.generate("image", {"prompt": "a mossy stone gate at dusk", "size": "1024x1024"})
if img.ok:
	$Poster.texture = ImageTexture.create_from_image(img.image)   # img.image is an Image
```

## Input

| Field | Rule |
| --- | --- |
| prompt | 1 to 4,000 characters |
| size | `512x512`, `1024x1024`, `1024x1536` or `1536x1024` |
| reference_image | Optional PNG, JPEG or WebP, up to 4 MiB |

## Result

The image and `usage.images`. The model is the game's default image model (`summer router limits get`).

Images made in the editor for your game's art belong in Summer Studio, not here. Use runtime images for content that depends on the player.

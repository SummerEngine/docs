A failed call never stops the game. The result has `ok` set to `false`, a stable `error` tag, a one-line `fix` and a `docs_url` to the tag below. Branch on the tag and show the character's offline line.

```gdscript
var r: SummerRouterResult = await Summer.client.router.reply("guard", line)
if r.ok:
    $Subtitle.text = r.text
else:
    $Subtitle.text = "The guard ignores you."
    push_warning("%s: %s" % [r.error, r.fix])
```

### unavailable

Keep the offline fallback. Summer Router needs the Summer Player Host and a configured gateway.

### not_signed_in

Ask the player to sign in to Summer, then try again.

### not_on_summer_games

Summer Router works on games published on Summer Games during early preview. Publish the game on Summer Games; other platforms and storefronts are coming soon. Keep the offline fallback.

### mic_denied

Fall back to text. Do not send the player to Settings.

### character_not_found

Push the character with `summer router push`, then call it by its id.

### tool_unhandled

Add a handler for this tool to the session's tools before the character calls it.

### mic_needs_player_action

Call request_access() from the talk button's pressed signal, not from \_ready(), a timer or a cutscene.

### limit_reached

Wait until resets_at, or raise the cap in Studio or with `summer router limits set`.

### credits_required

The game's owner adds credits in Studio.

### router_disabled

Turn on Summer Router for this game in Studio or with `summer router limits set`.

### age_restricted

Keep the offline fallback for this player.

### provider_unavailable

Retry later. The game keeps running.

### moderated

The provider's safety filter blocked this turn. Rephrase, or show the fallback line.

### invalid_input

Send inputs that match the kind's schema in the registry.

### rate_limited

Slow down and retry after Retry-After seconds.

## What your team gets

- Two tabs, **Items** and **Quests**, each a searchable, sortable table. Click a row to edit it in a dialog.
- Quest status as badges: draft, in review, done. Filter by status with one click.
- A reference check: quests that reward an item that does not exist are flagged.
- Your agent adds and changes items and quests by asking ("make the Iron Sword cost 120 gold", "add a fetch quest in Mossbank").

## Ask your agent

<Prompt description="**Item and quest database.** Your agent builds, seeds and checks the app.">
Build us a Summer App called "Game database" with two tabs: Items (name, type, rarity,
price, description) and Quests (title, giver, region, minimum level, status draft /
review / done, reward gold, reward items, steps). Search and a status filter above each
table, click a row to edit it in a dialog, and flag quests whose reward items do not
exist. Keep all data in the app's shared data. Give agents a check_references tool. Seed it with our items and
quests using apps.write_data with "as": "seed". Follow the summer-apps and
summer-apps-design skills, then check it with apps.screenshot (default, width 390,
theme dark) and fix what it reports.
</Prompt>

## Seed the data

One `apps.write_data` call writes every starter row in one revision. `"as": "seed"` marks the rows as the team's, with no author.

```json
{
  "appId": "<app id>",
  "as": "seed",
  "ops": [
    { "op": "put", "collection": "items", "recordId": "iron-sword", "data": { "name": "Iron Sword", "type": "weapon", "rarity": "common", "price": 100, "description": "A plain, honest blade." } },
    { "op": "put", "collection": "items", "recordId": "moss-cloak", "data": { "name": "Moss Cloak", "type": "armour", "rarity": "rare", "price": 340, "description": "Quiet in the forest." } },
    { "op": "put", "collection": "items", "recordId": "healing-draught", "data": { "name": "Healing Draught", "type": "consumable", "rarity": "common", "price": 25, "description": "Restores 50 health." } },
    { "op": "put", "collection": "items", "recordId": "drowned-bell", "data": { "name": "Drowned Bell", "type": "quest", "rarity": "epic", "price": 0, "description": "It still rings under water." } },
    { "op": "put", "collection": "quests", "recordId": "the-drowned-bell", "data": { "title": "The Drowned Bell", "giver": "Old Maren", "region": "Mossbank", "minLevel": 4, "status": "review", "rewardGold": 450, "rewardItems": ["moss-cloak"], "steps": ["Find the bell in the flooded chapel", "Ring it three times", "Return to Old Maren"] } },
    { "op": "put", "collection": "quests", "recordId": "supplies-for-the-ferry", "data": { "title": "Supplies for the Ferry", "giver": "Tobin", "region": "Mossbank", "minLevel": 2, "status": "draft", "rewardGold": 120, "rewardItems": ["healing-draught", "rope"], "steps": ["Bring Tobin five planks", "Bring Tobin a rope"] } }
  ]
}
```

The second quest rewards `rope`, which is not an item. The app flags it, and `check_references` returns it.

## An agent edit: "make the Iron Sword cost 120 gold"

Read the items with `apps.read_data`:

```json
{ "appId": "<app id>", "collection": "items" }
```

In the answer, `iron-sword` has `"price": 100` and a `revision`, here `1`. Write the change with `apps.write_data`, and add the missing rope item in the same revision. `"ifRevision": 0` adds the rope only if no record `rope` exists yet:

```json
{
  "appId": "<app id>",
  "ops": [
    { "op": "patch", "collection": "items", "recordId": "iron-sword", "patch": { "price": 120 }, "ifRevision": 1 },
    { "op": "put", "collection": "items", "recordId": "rope", "data": { "name": "Rope", "type": "material", "rarity": "common", "price": 5, "description": "Ten metres of hemp." }, "ifRevision": 0 }
  ]
}
```

A `conflict` means a record changed or already exists: read again and retry. The flag on "Supplies for the Ferry" goes away for everyone with the app open.

## What it uses

**SDK:** `summer.ready`; `summer.data.collection("items")` and `summer.data.collection("quests")` with `.list()`, `.put()`, `.patch()`, `.remove()` and `.subscribe()`; `summer.agent.send("record.saved")` after a dialog save; `summer.agent.tool("check_references")`; `summer.page.declare()` with **Add item** and **Add quest** actions.

**Kit:** `summer-page` with **Add item** or **Add quest** (for the open tab) in `slot="actions"`; `summer-tabs` (`labels` `["Items", "Quests"]`); `summer-toolbar` with `summer-search` and `summer-segmented` (status, with counts); `summer-table` (`row-key="id"`, `sortable`, `clickable`; a status column with `badges` `{ "draft": "quiet", "review": { "tone": "info", "label": "In review" }, "done": "ok" }`; a reference column of `type: "badge"` filled only on broken rows); `summer-dialog` with `summer-form`, `summer-text-input`, `summer-select` and a `type="number"` input; `summer-empty-state`; `summer-notice` for a failed load.

The reference check, used by the table and by the tool:

```js
async function brokenReferences() {
  const [items, quests] = await Promise.all([
    summer.data.collection("items").list({ limit: 500 }),
    summer.data.collection("quests").list({ limit: 500 }),
  ]);
  const ids = new Set(items.records.map((r) => r.recordId));
  const rewarded = new Set();
  const broken = [];
  for (const q of quests.records) {
    for (const id of q.data.rewardItems ?? []) {
      rewarded.add(id);
      if (!ids.has(id)) broken.push({ quest: q.recordId, item: id });
    }
  }
  return { broken, unused: [...ids].filter((id) => !rewarded.has(id)) };
}
summer.agent.tool("check_references", () => brokenReferences());
```

## What your team gets

- One loot table at a time (pick it from a menu): every drop with its weight, quantity and rarity.
- The real numbers: chance per roll (weight divided by the table's total weight) and chance per kill or open (with the table's number of rolls).
- A pie chart of the table. Edit weights in place and save.
- Your agent changes drops by asking ("halve the Moonfang chance from wolves", "make the Ember Staff a 2% drop from the boss chest").

## Ask your agent

<Prompt description="**Loot table editor.** Your agent builds, seeds and checks the app.">
Build us a Summer App called "Loot tables": pick a loot table from a menu, then see
every drop with weight, quantity, rarity, chance per roll (weight / total weight) and
chance per kill (1 - (1 - chance per roll) ^ rolls). Weights are editable in place with
a save bar, and a pie chart shows the table. Give agents a set_chance tool that sets one
drop to an exact chance per roll. Seed it with our loot tables using apps.write_data with
"as": "seed". Follow the summer-apps and summer-apps-design skills, then check it with
apps.screenshot (default, width 390, theme dark) and fix what it reports.
</Prompt>

## An agent edit: "halve the Moonfang chance from wolves"

Read the drops with `apps.read_data`:

```json
{ "appId": "<app id>", "collection": "drops" }
```

In the answer, `wolf-moonfang` has `"weight": 1` and a `revision`, here `1`. Halve the weight with `apps.write_data`:

```json
{
  "appId": "<app id>",
  "ops": [
    { "op": "patch", "collection": "drops", "recordId": "wolf-moonfang", "patch": { "weight": 0.5 }, "ifRevision": 1 }
  ]
}
```

The Moonfang chance per wolf goes from 1% to about 0.5% (0.5 of 99.5). A `conflict` means someone changed the drop: read again and retry. For an exact chance, call the app's tool while the person has it open: `apps.call` with `{ "tool": "set_chance", "input": { "drop": "chest-staff", "percent": 2 } }`.

## What it uses

**SDK:** `summer.ready` (its `params` for the starting table); `summer.data.collection("tables")` and `summer.data.collection("drops")` with `.list()`, `.get()`, `.patch()` and `.subscribe()`; `summer.data.commands()` to save table edits in one revision; `summer.agent.tool("set_chance")`; `summer.page.declare()` with a `choice` field for the table.

**Kit:** `summer-page`; `summer-section` with `summer-select` in `slot="aside"` to pick the table; `summer-stats` and `summer-stat` (drops, rolls, the rarest drop's chance per kill); `summer-table` (`row-key="id"`, `sortable`; an `editable` weight column with `format: "number"`; chance columns with `format: "percent"` and `digits: 1`, which take a fraction from 0 to 1); `summer-chart` (`kind="pie"`, `x="item"`, `y` `["weight"]`); `summer-save-bar`; `summer-dialog` with `summer-form` to add a drop.

The chances, and the weight for an exact chance:

```js
function chances(drops, rolls) {
  const total = drops.reduce((sum, d) => sum + d.weight, 0);
  return drops.map((d) => {
    const perRoll = total ? d.weight / total : 0;
    return { ...d, perRoll, perKill: 1 - (1 - perRoll) ** rolls };
  });
}
// The weight w that gives drop d a chance p, keeping the other weights: w = p * others / (1 - p)
summer.agent.tool("set_chance", async ({ drop, percent }) => {
  const drops = summer.data.collection("drops");
  const target = await drops.get(drop);
  if (!target) throw new Error(`No drop ${drop}`);
  const { records } = await drops.list({ limit: 500 });
  const others = records.filter((r) => r.data.table === target.data.table && r.recordId !== drop).reduce((sum, r) => sum + r.data.weight, 0);
  const p = percent / 100;
  const weight = Math.round((p * others / (1 - p)) * 1000) / 1000;
  await drops.patch(drop, { weight }, { ifRevision: target.revision });
  return { drop, weight };
});
```
